7 - Indo Além da Linearidade

Até agora, neste livro, nos concentramos principalmente em modelos lineares. Modelos lineares são relativamente simples de descrever e implementar e têm vantagens sobre outras abordagens em termos de interpretação e inferência. No entanto, a regressão linear padrão pode ter limitações significativas em termos de poder preditivo. Isso ocorre porque a suposição de linearidade é quase sempre uma aproximação, e às vezes uma aproximação ruim. No Capítulo 6, vimos que podemos melhorar os mínimos quadrados usando regressão de crista, lasso, regressão por componentes principais e outras técnicas. Nesse contexto, a melhoria é obtida reduzindo a complexidade do modelo linear e, portanto, a variância das estimativas. Mas ainda estamos usando um modelo linear, que só pode ser melhorado até certo ponto! Neste capítulo, relaxamos a suposição de linearidade enquanto ainda tentamos manter o máximo de interpretabilidade possível. Fazemos isso examinando extensões muito simples de modelos lineares, como regressão polinomial e funções em degraus, bem como abordagens mais sofisticadas, como splines, regressão local e modelos aditivos generalizados.

  • A regressão polinomial estende o modelo linear adicionando preditores extras, obtidos elevando cada um dos preditores originais a uma potência. Por exemplo, uma regressão cúbica usa três variáveis, \(X\), \(X^2\) e \(X^3\), como preditores. Essa abordagem fornece uma maneira simples de fornecer um ajuste não linear aos dados.

  • Funções em degraus dividem o intervalo de uma variável em \(K\) regiões distintas para produzir uma variável qualitativa. Isso tem o efeito de ajustar uma função constante por partes.

  • Splines de regressão são mais flexíveis do que polinômios e funções em degraus e, na verdade, são uma extensão dos dois. Eles envolvem dividir o intervalo de \(X\) em \(K\) regiões distintas. Dentro de cada região, uma função polinomial é ajustada aos dados. No entanto, esses polinômios são restritos para que se juntem suavemente nas fronteiras das regiões, ou nós. Desde que o intervalo seja dividido em regiões suficientes, isso pode produzir um ajuste extremamente flexível.

  • Splines de suavização são semelhantes aos splines de regressão, mas surgem em uma situação ligeiramente diferente. Splines de suavização resultam da minimização de um critério de soma de quadrados dos resíduos sujeito a uma penalidade de suavidade.

  • A regressão local é semelhante aos splines, mas difere de uma maneira importante. As regiões podem se sobrepor e, de fato, o fazem de uma maneira muito suave.

  • Modelos aditivos generalizados nos permitem estender os métodos acima para lidar com múltiplos preditores.

Nas Seções 7.1–7.6, apresentamos várias abordagens para modelar a relação entre uma resposta \(Y\) e um único preditor \(X\) de forma flexível. Na Seção 7.7, mostramos que essas abordagens podem ser integradas perfeitamente para modelar uma resposta \(Y\) como uma função de vários preditores \(X_1, \ldots, X_p\).

7.1 - Regressão Polinomial

Historicamente, a maneira padrão de estender a regressão linear para configurações em que a relação entre os preditores e a resposta é não linear tem sido substituir o modelo linear padrão \[ y_i = \beta_0 + \beta_1 x_i + \epsilon_i \] por uma função polinomial \[ y_i = \beta_0 + \beta_1 x_i + \beta_2 x_i^2 + \beta_3 x_i^3 + \cdots + \beta_d x_i^d + \epsilon_i, \] onde \(\epsilon_i\) é o termo de erro. Essa abordagem é conhecida como regressão polinomial, e de fato vimos um exemplo desse método na Seção 3.3.2. Para um grau \(d\) suficientemente grande, uma regressão polinomial nos permite produzir uma curva extremamente não linear. Note que os coeficientes em (7.1) podem ser facilmente estimados usando a regressão linear de mínimos quadrados, porque este é apenas um modelo linear padrão com preditores \(x_i, x_i^2, x_i^3, \ldots, x_i^d\). Geralmente falando, é incomum usar \(d\) maior que 3 ou 4, porque para valores grandes de \(d\), a curva polinomial pode se tornar excessivamente flexível e assumir algumas formas muito estranhas. Isso é especialmente verdadeiro perto da fronteira da variável \(X\).

O painel da esquerda na Figura 7.1 é um gráfico de wage contra idade para o conjunto de dados Wage, que contém informações de renda e demográficas para homens que residem na região central do Atlântico dos Estados Unidos. Vemos os resultados do ajuste de um polinômio de grau 4 usando mínimos quadrados (curva azul sólida). Embora este seja um modelo de regressão linear como qualquer outro, os coeficientes individuais não são de particular interesse. Em vez disso, observamos toda a função ajustada em uma grade de 63 valores para a idade, de 18 a 80, para entender a relação entre idade e salário.

Na Figura 7.1, um par de curvas tracejadas acompanha o ajuste; essas são curvas de erro padrão (2×). Vamos ver como elas surgem. Suponha que tenhamos calculado o ajuste em um valor particular de idade, \(x_0\): \[ \hat{f}(x_0) = \hat{\beta}_0 + \hat{\beta}_1 x_0 + \hat{\beta}_2 x_0^2 + \hat{\beta}_3 x_0^3 + \hat{\beta}_4 x_0^4. \]

Qual é a variância do ajuste, ou seja, \(\text{Var} \hat{f}(x_0)\)? Os mínimos quadrados retornam estimativas de variância para cada um dos coeficientes ajustados \(\hat{\beta}_j\), bem como as covariâncias entre os pares de estimativas dos coeficientes. Podemos usar essas estimativas para calcular a variância estimada de \(\hat{f}(x_0)\). A estimativa do erro padrão pontual de \(f(x_0)\) é a raiz quadrada dessa variância. Essa computação é repetida em cada ponto de referência \(x_0\), e plotamos a curva ajustada, bem como duas vezes o erro padrão de cada lado da curva ajustada. Plotamos duas vezes o erro padrão porque, para termos de erro distribuídos normalmente, essa quantidade corresponde a um intervalo de confiança de aproximadamente 95%.

Parece que os salários na Figura 7.1 são de duas populações distintas: parece haver um grupo de altos ganhos ganhando mais de $250,000 por ano, bem como um grupo de baixos ganhos. Podemos tratar wage como uma variável binária, dividindo-a nesses dois grupos. A regressão logística pode então ser usada para prever essa resposta binária, usando funções polinomiais da idade como preditores. Em outras palavras, ajustamos o modelo.

\[ \text{Pr}(y_i > 250|x_i) = \frac{\exp(\beta_0 + \beta_1 x_i + \beta_2 x_i^2 + \cdots + \beta_d x_i^d)}{1 + \exp(\beta_0 + \beta_1 x_i + \beta_2 x_i^2 + \cdots + \beta_d x_i^d)}. \]

O resultado é mostrado no painel da direita da Figura 7.1. As marcas cinzas na parte superior e inferior do painel indicam as idades dos altos ganhos e dos baixos ganhos. A curva azul sólida indica as probabilidades ajustadas de ser um alto ganhador, como função da idade. O intervalo de confiança estimado de 95% também é mostrado. Vemos que aqui os intervalos de confiança são bastante amplos, especialmente no lado direito. Embora o tamanho da amostra para este conjunto de dados seja substancial (\(n = 3,000\)), há apenas 79 altos ganhos, o que resulta em alta variância nas estimativas dos coeficientes e, consequentemente, intervalos de confiança amplos.

7.2 - Funções de Degrau

Usar funções polinomiais das características como preditores em um modelo linear impõe uma estrutura global à função não linear de \(X\). Podemos, em vez disso, usar funções em degraus para evitar impor tal estrutura global. Aqui, dividimos o intervalo de \(X\) em intervalos e ajustamos uma constante diferente em cada intervalo. Isso equivale a converter uma variável contínua em uma variável categórica ordenada.

Em mais detalhes, criamos pontos de corte \(c_1, c_2, \ldots, c_K\) no intervalo de \(X\), e então construímos \(K + 1\) novas variáveis: \[ C_0(X) = I(X < c_1), \\ C_1(X) = I(c_1 \leq X < c_2), \\ C_2(X) = I(c_2 \leq X < c_3), \\ \vdots \\ C_{K-1}(X) = I(c_{K-1} \leq X < c_K), \\ C_K(X) = I(c_K \leq X), \] onde \(I(\cdot)\) é uma função indicadora que retorna 1 se a condição for verdadeira e retorna 0 caso contrário. Por exemplo, \(I(c_K \leq X)\) é igual a 1 se \(c_K \leq X\), e é igual a 0 caso contrário. Essas são às vezes chamadas de variáveis dummy. Note que para qualquer valor de \(X\), \(C_0(X) + C_1(X) + \cdots + C_K(X) = 1\), pois \(X\) deve estar exatamente em um dos \(K + 1\) intervalos. Em seguida, usamos mínimos quadrados para ajustar um modelo linear usando \(C_1(X), C_2(X), \ldots, C_K(X)\) como preditores: \[ y_i = \beta_0 + \beta_1 C_1(x_i) + \beta_2 C_2(x_i) + \cdots + \beta_K C_K(x_i) + \epsilon_i. \]

FIGURA 7.2. Os dados de Wage. Esquerda: A curva sólida exibe o valor ajustado de uma regressão de mínimos quadrados de wage (em milhares de dólares) usando funções em degraus de idade. As curvas tracejadas indicam um intervalo de confiança estimado de 95%. Direita: Modelamos o evento binário wage > 250 usando regressão logística, novamente usando funções em degraus de idade. A probabilidade posterior ajustada de wage exceder \(250,000\) é mostrada, juntamente com um intervalo de confiança estimado de 95%.

Para um dado valor de \(X\), no máximo uma de \(C_1, C_2, \ldots, C_K\) pode ser diferente de zero. Note que quando \(X < c_1\), todos os preditores em (7.5) são zero, então \(\beta_0\) pode ser interpretado como o valor médio de \(Y\) para \(X < c_1\). Em comparação, (7.5) prevê uma resposta de \(\beta_0 + \beta_j\) para \(c_j \leq X < c_{j+1}\), então \(\beta_j\) representa o aumento médio na resposta para \(X\) em \(c_j \leq X < c_{j+1}\) em relação a \(X < c_1\).

Um exemplo de ajuste de funções em degraus aos dados de Wage da Figura 7.1 é mostrado no painel da esquerda da Figura 7.2. Também ajustamos o modelo de regressão logística \[ \text{Pr}(y_i > 250 | x_i) = \frac{\exp(\beta_0 + \beta_1 C_1(x_i) + \cdots + \beta_K C_K(x_i))}{1 + \exp(\beta_0 + \beta_1 C_1(x_i) + \cdots + \beta_K C_K(x_i))} \] para prever a probabilidade de que um indivíduo seja um alto ganhador com base na idade. O painel da direita da Figura 7.2 exibe as probabilidades posteriores ajustadas obtidas usando essa abordagem.

Infelizmente, a menos que haja pontos de corte naturais nos preditores, funções constantes por partes podem perder a ação. Por exemplo, no painel da esquerda da Figura 7.2, o primeiro intervalo claramente perde a tendência crescente de wage com a idade. No entanto, abordagens de funções em degraus são muito populares em bioestatística e epidemiologia, entre outras disciplinas. Por exemplo, grupos de idade de 5 anos são frequentemente usados para definir os intervalos.

7.3 - Funções Base

Modelos de regressão polinomial e constantes por partes são, na verdade, casos especiais de uma abordagem de funções base. A ideia é ter em mãos uma família de funções ou transformações que podem ser aplicadas a uma variável \(X\): \(b_1(X), b_2(X), \ldots, b_K(X)\). Em vez de ajustar um modelo linear em \(X\), ajustamos o modelo \[ y_i = \beta_0 + \beta_1 b_1(x_i) + \beta_2 b_2(x_i) + \beta_3 b_3(x_i) + \cdots + \beta_K b_K(x_i) + \epsilon_i. \]

Note que as funções base \(b_1(\cdot), b_2(\cdot), \ldots, b_K(\cdot)\) são fixas e conhecidas. (Em outras palavras, escolhemos as funções com antecedência.) Para a regressão polinomial, as funções base são \(b_j(x_i) = x_i^j\), e para funções constantes por partes, elas são \(b_j(x_i) = I(c_j \leq x_i < c_{j+1})\). Podemos pensar em (7.7) como um modelo linear padrão com preditores \(b_1(x_i), b_2(x_i), \ldots, b_K(x_i)\). Portanto, podemos usar mínimos quadrados para estimar os coeficientes de regressão desconhecidos em (7.7). Importante, isso significa que todas as ferramentas de inferência para modelos lineares discutidas no Capítulo 3, como erros padrão para as estimativas dos coeficientes e estatísticas F para a significância geral do modelo, estão disponíveis nesse contexto.

Até agora, consideramos o uso de funções polinomiais e funções constantes por partes como nossas funções base; no entanto, muitas alternativas são possíveis. Por exemplo, podemos usar wavelets ou séries de Fourier para construir funções base. Na próxima seção, investigamos uma escolha muito comum para uma função base: splines de regressão.

7.4 - Splines de Regressão

Agora discutimos uma classe flexível de funções base que se estende sobre as abordagens de regressão polinomial e regressão constante por partes que acabamos de ver.

7.4.1 - Polinômios Segmentados

Em vez de ajustar um polinômio de alta ordem em todo o intervalo de \(X\), a regressão polinomial por partes envolve ajustar polinômios de baixa ordem separados em diferentes regiões de \(X\). Por exemplo, um polinômio cúbico por partes funciona ajustando um modelo de regressão cúbica da forma \[ y_i = \beta_0 + \beta_1 x_i + \beta_2 x_i^2 + \beta_3 x_i^3 + \epsilon_i, \] onde os coeficientes \(\beta_0, \beta_1, \beta_2\) e \(\beta_3\) diferem em diferentes partes do intervalo de \(X\). Os pontos onde os coeficientes mudam são chamados de nós.

Por exemplo, um cúbico por partes sem nós é apenas um polinômio cúbico padrão, como em (7.1) com \(d = 3\). Um polinômio cúbico por partes com um único nó em um ponto \(c\) assume a forma \[ y_i = \begin{cases} \beta_{01} + \beta_{11} x_i + \beta_{21} x_i^2 + \beta_{31} x_i^3 + \epsilon_i & \text{se } x_i < c \\ \beta_{02} + \beta_{12} x_i + \beta_{22} x_i^2 + \beta_{32} x_i^3 + \epsilon_i & \text{se } x_i \geq c \end{cases} \]

Em outras palavras, ajustamos duas funções polinomiais diferentes aos dados, uma no subconjunto das observações com \(x_i < c\), e outra no subconjunto das observações com \(x_i \geq c\). A primeira função polinomial tem coeficientes \(\beta_{01}, \beta_{11}, \beta_{21}\) e \(\beta_{31}\), e a segunda tem coeficientes \(\beta_{02}, \beta_{12}, \beta_{22}\) e \(\beta_{32}\). Cada uma dessas funções polinomiais pode ser ajustada usando mínimos quadrados aplicados a funções simples do preditor original.

Usar mais nós leva a um polinômio por partes mais flexível. Em geral, se colocarmos \(K\) nós diferentes ao longo do intervalo de \(X\), então acabaremos ajustando \(K + 1\) polinômios cúbicos diferentes. Note que não precisamos usar um polinômio cúbico. Por exemplo, podemos ajustar funções lineares por partes. De fato, nossas funções constantes por partes da Seção 7.2 são polinômios por partes de grau 0!

O painel superior esquerdo da Figura 7.3 mostra um polinômio cúbico por partes ajustado a um subconjunto dos dados de Wage, com um único nó em age = 50. Imediatamente vemos um problema: a função é descontínua e parece ridícula

7.4.2 - Restrições e Splines

O painel superior esquerdo da Figura 7.3 parece errado porque a curva ajustada é muito flexível. Para corrigir esse problema, podemos ajustar um polinômio por partes sob a condição de que a curva ajustada deve ser contínua. Em outras palavras, não pode haver um salto quando a idade = 50. O gráfico superior direito na Figura 7.3 mostra o ajuste resultante. Isso parece melhor do que o gráfico superior esquerdo, mas a junção em forma de V parece antinatural.

As splines de regressão que acabamos de ver na seção anterior podem ter parecido um pouco complexas: como podemos ajustar um polinômio por partes de grau \(d\) sob a condição de que ele (e possivelmente suas primeiras \(d-1\) derivadas) seja contínuo? Acontece que podemos usar o modelo base (7.7) para representar uma spline de regressão. Uma spline cúbica com \(K\) nós pode ser modelada como \[ y_i = \beta_0 + \beta_1 b_1(x_i) + \beta_2 b_2(x_i) + \cdots + \beta_{K+3} b_{K+3}(x_i) + \epsilon_i, \] para uma escolha apropriada de funções base \(b_1, b_2, \ldots, b_{K+3}\). O modelo (7.9) pode então ser ajustado usando mínimos quadrados.

Assim como existem várias maneiras de representar polinômios, também existem muitas maneiras equivalentes de representar splines cúbicas usando diferentes escolhas de funções base em (7.9). A maneira mais direta de representar uma spline cúbica usando (7.9) é começar com uma base para um polinômio cúbico—ou seja, \(x, x^2\) e \(x^3\)—e então adicionar uma função base de potência truncada por nó. Uma função base de potência truncada é definida como \[ h(x, \xi) = (x - \xi)^3_+ = \begin{cases} (x - \xi)^3 & \text{se } x > \xi \\ 0 & \text{caso contrário} \end{cases} \] onde \(\xi\) é o nó. Pode-se mostrar que adicionar um termo da forma \(\beta_4 h(x, \xi)\) ao modelo (7.8) para um polinômio cúbico levará a uma descontinuidade apenas na terceira derivada em \(\xi\); a função permanecerá contínua, com derivadas primeira e segunda contínuas, em cada um dos nós.

Em outras palavras, para ajustar uma spline cúbica a um conjunto de dados com \(K\) nós, realizamos a regressão de mínimos quadrados com uma interceptação e \(3 + K\) preditores, da forma \(X, X^2, X^3, h(X, \xi_1), h(X, \xi_2), \ldots, h(X, \xi_K)\), onde \(\xi_1, \ldots, \xi_K\) são os nós. Isso equivale a estimar um total de \(K + 4\) coeficientes de regressão; por essa razão, ajustar uma spline cúbica com \(K\) nós usa \(K+4\) graus de liberdade.

FIGURA 7.4. Uma spline cúbica e uma spline cúbica natural, com três nós, ajustadas a um subconjunto dos dados de Wage. As linhas tracejadas denotam as localizações dos nós.

Infelizmente, as splines podem ter alta variância na extremidade do intervalo dos preditores—isto é, quando \(X\) assume um valor muito pequeno ou muito grande. A Figura 7.4 mostra um ajuste aos dados de Wage com três nós. Vemos que as bandas de confiança na região de fronteira parecem bastante instáveis. Uma spline natural é uma spline de regressão com restrições adicionais de fronteira: a função spline natural deve ser linear na fronteira (na região onde \(X\) é menor que o menor nó, ou maior que o maior nó). Essa restrição adicional significa que as splines naturais geralmente produzem estimativas mais estáveis nas fronteiras. Na Figura 7.4, uma spline cúbica natural também é exibida como uma linha vermelha. Note que os intervalos de confiança correspondentes são mais estreitos.

No gráfico inferior esquerdo, adicionamos duas restrições adicionais: agora as derivadas primeira e segunda dos polinômios por partes são contínuas em idade = 50. Em outras palavras, estamos exigindo que o polinômio por partes seja não apenas contínuo quando a idade = 50, mas também muito suave. Cada restrição que impomos aos polinômios cúbicos por partes efetivamente libera um grau de liberdade, reduzindo a complexidade do ajuste do polinômio por partes resultante. Então, no gráfico superior esquerdo, estamos usando oito graus de liberdade, mas no gráfico inferior esquerdo impusemos três restrições (continuidade, continuidade da primeira derivada e continuidade da segunda derivada) e, portanto, ficamos com cinco graus de liberdade. A curva no gráfico inferior esquerdo é chamada de spline cúbica. Em geral, uma spline cúbica com \(K\) nós usa um total de \(4 + K\) graus de liberdade.

Na Figura 7.3, o gráfico inferior direito é uma spline linear, que é contínua em idade = 50. A definição geral de uma spline de grau \(d\) é que é um polinômio por partes de grau \(d\), com continuidade nas derivadas até o grau \(d-1\) em cada nó. Portanto, uma spline linear é obtida ajustando uma linha em cada região do espaço do preditor definido pelos nós, exigindo continuidade em cada nó.

Na Figura 7.3, há um único nó em idade = 50. Claro, poderíamos adicionar mais nós e impor continuidade em cada um deles.

7.4.4 - Escolhendo o Número e as Localizações dos Nós

Quando ajustamos uma spline, onde devemos colocar os nós? A spline de regressão é mais flexível em regiões que contêm muitos nós, porque nessas regiões os coeficientes polinomiais podem mudar rapidamente. Assim, uma opção é colocar mais nós em lugares onde sentimos que a função pode variar mais rapidamente e colocar menos nós onde ela parece mais estável. Embora essa opção possa funcionar bem, na prática é comum colocar nós de forma uniforme. Uma maneira de fazer isso é especificar os graus de liberdade desejados e, em seguida, deixar que o software coloque automaticamente o número correspondente de nós em quantis uniformes dos dados.

A Figura 7.5 mostra um exemplo nos dados de Wage. Como na Figura 7.4, ajustamos uma spline cúbica natural com três nós, exceto que desta vez as localizações dos nós foram escolhidas automaticamente como os percentis 25, 50 e 75 da idade. Isso foi especificado solicitando quatro graus de liberdade. O argumento pelo qual quatro graus de liberdade levam a três nós interiores é um pouco técnico.

Quantos nós devemos usar, ou, de forma equivalente, quantos graus de liberdade nossa spline deve conter? Uma opção é testar diferentes números de nós e ver qual produz a melhor curva visual. Uma abordagem um pouco mais objetiva é usar validação cruzada, como discutido nos Capítulos 5 e 6. Com esse método, removemos uma parte dos dados (digamos 10%), ajustamos uma spline com um certo número de nós aos dados restantes e, em seguida, usamos a spline para fazer previsões para a parte retirada. Repetimos esse processo várias vezes até que cada observação tenha sido deixada de fora uma vez, e então calculamos o RSS geral validado por cruzamento. Esse procedimento pode ser repetido para diferentes números de nós \(K\). Então, o valor de \(K\) que dá o menor RSS é escolhido.

A Figura 7.6 mostra os erros médios quadráticos validados por cruzamento em dez divisões para splines com vários graus de liberdade ajustadas aos dados de Wage. O painel da esquerda corresponde a uma spline cúbica natural e o painel da direita a uma spline cúbica. Os dois métodos produzem resultados quase idênticos, com evidências claras de que um ajuste de um grau (uma regressão linear) não é adequado. Ambas as curvas se achatam rapidamente, e parece que três graus de liberdade para a spline natural e quatro graus de liberdade para a spline cúbica são bastante adequados.

Na Seção 7.7, ajustamos modelos de splines aditivas simultaneamente em várias variáveis ao mesmo tempo. Isso pode exigir potencialmente a seleção dos graus de liberdade para cada variável. Em casos como este, normalmente adotamos uma abordagem mais pragmática e definimos os graus de liberdade para um número fixo, digamos quatro, para todos os termos.

A Figura 7.7 compara uma spline cúbica natural com 15 graus de liberdade a um polinômio de grau 15 no conjunto de dados Wage. A flexibilidade extra no polinômio produz resultados indesejáveis nas extremidades, enquanto a spline cúbica natural ainda fornece um ajuste razoável aos dados. Isso ocorre porque, ao contrário dos polinômios, que devem usar um grau alto (expoente no termo monomial mais alto, por exemplo, \(X^{15}\)) para produzir ajustes flexíveis, as splines introduzem flexibilidade aumentando o número de nós, mas mantendo o grau fixo. Geralmente, essa abordagem produz estimativas mais estáveis. As splines também nos permitem colocar mais nós, e, portanto, flexibilidade, em regiões onde a função \(f\) parece estar mudando rapidamente, e menos nós onde \(f\) parece mais estável.

7.5 - Splines Suavizadores

Na última seção, discutimos as splines de regressão, que criamos especificando um conjunto de nós, produzindo uma sequência de funções base e, em seguida, usando mínimos quadrados para estimar os coeficientes da spline. Agora, introduzimos uma abordagem um pouco diferente que também produz uma spline.

7.5.1 - Uma Visão Geral dos Splines Suavizadores

Ao ajustar uma curva suave a um conjunto de dados, o que realmente queremos fazer é encontrar alguma função, digamos \(g(x)\), que ajuste bem os dados observados: ou seja, queremos que \[ \text{RSS} = \sum_{i=1}^n (y_i - g(x_i))^2 \] seja pequeno. No entanto, há um problema com essa abordagem. Se não colocarmos nenhuma restrição em \(g(x_i)\), então sempre podemos fazer o RSS ser zero simplesmente escolhendo \(g\) de modo que ela interpole todos os \(y_i\). Tal função ajustaria demais os dados—seria muito flexível. O que realmente queremos é uma função \(g\) que faça o RSS ser pequeno, mas que também seja suave.

Como podemos garantir que \(g\) seja suave? Existem várias maneiras de fazer isso. Uma abordagem natural é encontrar a função \(g\) que minimize \[ \sum_{i=1}^n (y_i - g(x_i))^2 + \lambda \int \left( g''(t) \right)^2 dt \] onde \(\lambda\) é um parâmetro de ajuste não negativo. A função \(g\) que minimiza (7.11) é conhecida como uma spline de suavização.

O que significa a equação (7.11)? A Equação 7.11 segue a formulação “Perda+Penalidade” que encontramos no contexto da regressão de crista e do lasso no Capítulo 6. O termo \(\sum_{i=1}^n (y_i - g(x_i))^2\) é uma função de perda que incentiva \(g\) a ajustar bem os dados, e o termo \(\lambda \int \left( g''(t) \right)^2 dt\) é um termo de penalidade que penaliza a variabilidade em \(g\). A notação \(g''(t)\) indica a segunda derivada da função \(g\). A primeira derivada \(g'(t)\) mede a inclinação de uma função em \(t\), e a segunda derivada corresponde ao quanto a inclinação está mudando. Assim, de maneira geral, a segunda derivada de uma função é uma medida de sua rugosidade: ela é grande em valor absoluto se \(g(t)\) é muito ondulante perto de \(t\), e é próxima de zero caso contrário. (A segunda derivada de uma linha reta é zero; note que uma linha é perfeitamente suave.) A notação \(\int\) é uma integral, que podemos pensar como uma soma sobre o intervalo de \(t\). Em outras palavras, \(\int \left( g''(t) \right)^2 dt\) é simplesmente uma medida da mudança total na função \(g'(t)\), ao longo de todo o seu intervalo. Se \(g\) for muito suave, então \(g'(t)\) será próximo de constante e \(\int \left( g''(t) \right)^2 dt\) terá um valor pequeno. Por outro lado, se \(g\) for muito variável, então \(g'(t)\) variará significativamente e \(\int \left( g''(t) \right)^2 dt\) terá um valor grande. Portanto, em (7.11), \(\lambda \int \left( g''(t) \right)^2 dt\) incentiva \(g\) a ser suave. Quanto maior o valor de \(\lambda\), mais suave \(g\) será.

Quando \(\lambda = 0\), o termo de penalidade em (7.11) não tem efeito, e assim a função \(g\) será muito variável e interpolará exatamente as observações de treinamento. Quando \(\lambda \to \infty\), \(g\) será perfeitamente suave—será apenas uma linha reta que passa o mais próximo possível dos pontos de treinamento. Na verdade, neste caso, \(g\) será a linha de mínimos quadrados linear, já que a função de perda em (7.11) equivale a minimizar a soma residual dos quadrados. Para um valor intermediário de \(\lambda\), \(g\) irá aproximar as observações de treinamento, mas será um pouco suave. Vemos que \(\lambda\) controla a troca entre viés e variância da spline de suavização.

Pode-se mostrar que a função \(g(x)\) que minimiza (7.11) possui algumas propriedades especiais: é um polinômio cúbico por partes com nós nos valores únicos de \(x_1, \ldots, x_n\), e derivadas primeira e segunda contínuas em cada nó. Além disso, é linear na região fora dos nós extremos. Em outras palavras, a função \(g(x)\) que minimiza (7.11) é uma spline cúbica natural com nós em \(x_1, \ldots, x_n\)! No entanto, não é a mesma spline cúbica natural que se obteria se aplicássemos a abordagem de função base descrita na Seção 7.4.3 com nós em \(x_1, \ldots, x_n\)—em vez disso, é uma versão reduzida de tal spline cúbica natural, onde o valor do parâmetro de ajuste \(\lambda\) em (7.11) controla o nível de redução.

7.5.2 - Escolhendo o Parâmetro de Suavização

Vimos que uma spline de suavização é simplesmente uma spline cúbica natural com nós em cada valor único de \(x_i\). Pode parecer que uma spline de suavização terá muitos graus de liberdade, já que um nó em cada ponto de dado permite uma grande flexibilidade. Mas o parâmetro de ajuste \(\lambda\) controla a rugosidade da spline de suavização e, portanto, os graus de liberdade efetivos. É possível mostrar que, à medida que \(\lambda\) aumenta de 0 para \(\infty\), os graus de liberdade efetivos, que escrevemos como \(df_\lambda\), diminuem de \(n\) para 2.

No contexto das splines de suavização, por que discutimos graus de liberdade efetivos em vez de graus de liberdade? Normalmente, graus de liberdade se referem ao número de parâmetros livres, como o número de coeficientes ajustados em um polinômio ou spline cúbica. Embora uma spline de suavização tenha \(n\) parâmetros e, portanto, \(n\) graus de liberdade nominais, esses \(n\) parâmetros são fortemente restritos ou reduzidos. Portanto, \(df_\lambda\) é uma medida da flexibilidade da spline de suavização—quanto maior for, mais flexível (e menor viés, mas maior variância) será a spline de suavização. A definição de graus de liberdade efetivos é um tanto técnica. Podemos escrever \[ \hat{g}_\lambda = S_\lambda y, \] onde \(\hat{g}_\lambda\) é a solução para (7.11) para uma escolha particular de \(\lambda\)—ou seja, é um vetor \(n\)-dimensional contendo os valores ajustados da spline de suavização nos pontos de treinamento \(x_1, \ldots, x_n\). A Equação 7.12 indica que o vetor de valores ajustados ao aplicar uma spline de suavização aos dados pode ser escrito como uma matriz \(n \times n\) \(S_\lambda\) (para a qual existe uma fórmula) vezes o vetor de respostas \(y\). Então, os graus de liberdade efetivos são definidos como \[ df_\lambda = \sum_{i=1}^n \{S_\lambda\}_{ii}, \] a soma dos elementos diagonais da matriz \(S_\lambda\).

Ao ajustar uma spline de suavização, não precisamos selecionar o número ou a localização dos nós—haverá um nó em cada observação de treinamento, \(x_1, \ldots, x_n\). Em vez disso, temos outro problema: precisamos escolher o valor de \(\lambda\). Não é surpresa que uma possível solução para esse problema seja a validação cruzada. Em outras palavras, podemos encontrar o valor de \(\lambda\) que faz com que o RSS validado por cruzamento seja o menor possível. Acontece que o erro de validação cruzada por exclusão (LOOCV) pode ser computado de maneira muito eficiente para splines de suavização, com essencialmente o mesmo custo de computação de um único ajuste, usando a seguinte fórmula: \[ \text{RSS}_{cv}(\lambda) = \sum_{i=1}^n \left( \frac{y_i - \hat{g}_\lambda(x_i)}{1 - \{S_\lambda\}_{ii}} \right)^2. \]

A notação \(\hat{g}_{\lambda(-i)}(x_i)\) indica o valor ajustado para essa spline de suavização avaliada em \(x_i\), onde o ajuste usa todas as observações de treinamento, exceto a \(i\)-ésima observação \((x_i, y_i)\). Em contraste, \(\hat{g}_\lambda(x_i)\) indica a função spline de suavização ajustada a todas as observações de treinamento e avaliada em \(x_i\). Essa fórmula notável diz que podemos computar cada um desses ajustes por exclusão usando apenas \(\hat{g}_\lambda\), o ajuste original a todos os dados! Temos uma fórmula muito semelhante (5.2) na página 202 do Capítulo 5 para regressão linear de mínimos quadrados. Usando (5.2), podemos realizar muito rapidamente a LOOCV para as splines de regressão discutidas anteriormente neste capítulo, bem como para a regressão de mínimos quadrados usando funções base arbitrárias.

A Figura 7.8 mostra os resultados do ajuste de uma spline de suavização aos dados de Wage. A curva vermelha indica o ajuste obtido ao pré-especificar que gostaríamos de uma spline de suavização com 16 graus de liberdade efetivos. A curva azul é a spline de suavização obtida quando \(\lambda\) é escolhido usando LOOCV; nesse caso, o valor de \(\lambda\) escolhido resulta em 6,8 graus de liberdade efetivos (computados usando (7.13)). Para esses dados, há pouca diferença discernível entre as duas splines de suavização, além do fato de que a com 16 graus de liberdade parece ligeiramente mais ondulante. Como há pouca diferença entre os dois ajustes, a spline de suavização ajustada com 6,8 graus de liberdade é preferível, já que, em geral, modelos mais simples são melhores, a menos que os dados forneçam evidências em apoio a um modelo mais complexo.

7.6 - Regressão Local

A regressão local é uma abordagem diferente para ajustar funções não lineares flexíveis, que envolve calcular o ajuste em um ponto alvo \(x_0\) usando apenas as observações de treinamento próximas. A Figura 7.9 ilustra a ideia em alguns dados simulados, com um ponto alvo perto de 0.4 e outro perto da fronteira em 0.05. Nesta figura, a linha azul representa a função \(f(x)\) a partir da qual os dados foram gerados, e a linha laranja clara corresponde à estimativa da regressão local \(\hat{f}(x)\). A regressão local é descrita no Algoritmo 7.1.

Observe que no Passo 3 do Algoritmo 7.1, os pesos \(K_{i0}\) serão diferentes para cada valor de \(x_0\). Em outras palavras, para obter o ajuste da regressão local em um novo ponto, precisamos ajustar um novo modelo de regressão de mínimos quadrados ponderados minimizando (7.14) para um novo conjunto de pesos. A regressão local é às vezes referida como um procedimento baseado em memória, porque, como os vizinhos mais próximos, precisamos de todos os dados de treinamento cada vez que desejamos calcular uma previsão. Evitaremos entrar nos detalhes técnicos da regressão local aqui—há livros escritos sobre o tópico.

Para realizar a regressão local, há várias escolhas a serem feitas, como definir a função de ponderação \(K\), e se ajustar uma regressão linear, constante ou quadrática no Passo 3. (A Equação 7.14 corresponde a uma regressão linear.) Embora todas essas escolhas façam alguma diferença, a escolha mais importante é o intervalo \(s\), que é a proporção de pontos usados para calcular a regressão local em \(x_0\), conforme definido no Passo 1 acima. O intervalo desempenha um papel semelhante ao do parâmetro de ajuste \(\lambda\) em splines de suavização: ele controla a flexibilidade do ajuste não linear. Quanto menor o valor de \(s\), mais local e ondulante será nosso ajuste; alternativamente, um valor muito grande de \(s\) levará a um ajuste global aos dados usando todas as observações de treinamento. Podemos novamente usar validação cruzada para escolher \(s\), ou podemos especificá-lo diretamente. A Figura 7.10 exibe ajustes de regressão linear local nos dados de Wage, usando dois valores de \(s\): 0.7 e 0.2. Como esperado, o ajuste obtido usando \(s = 0.7\) é mais suave do que o obtido usando \(s = 0.2\).

Algoritmo 7.1 Regressão Local em \(X = x_0\)

  1. Coletar a fração \(s = k/n\) dos pontos de treinamento cujos \(x_i\) estão mais próximos de \(x_0\).

  2. Atribuir um peso \(K_{i0} = K(x_i, x_0)\) a cada ponto neste vizinhança, de modo que o ponto mais distante de \(x_0\) tenha peso zero, e o mais próximo tenha o maior peso. Todos, exceto esses \(k\) vizinhos mais próximos, recebem peso zero.

  3. Ajustar uma regressão de mínimos quadrados ponderados de \(y_i\) em \(x_i\) usando os pesos mencionados, encontrando \(\hat{\beta}_0\) e \(\hat{\beta}_1\) que minimizam \[ \sum_{i=1}^n K_{i0} (y_i - \beta_0 - \beta_1 x_i)^2. \]

  4. O valor ajustado em \(x_0\) é dado por \(\hat{f}(x_0) = \hat{\beta}_0 + \hat{\beta}_1 x_0\).

A ideia da regressão local pode ser generalizada de muitas maneiras diferentes. Em um cenário com múltiplas características \(X_1, X_2, \ldots, X_p\), uma generalização muito útil envolve ajustar um modelo de regressão linear múltipla que é global em algumas variáveis, mas local em outras, como o tempo. Tais modelos de coeficientes variáveis são uma maneira útil de adaptar um modelo aos dados mais recentemente coletados. A regressão local também se generaliza de forma muito natural quando queremos ajustar modelos que são locais em um par de variáveis \(X_1\) e \(X_2\), em vez de uma. Podemos simplesmente usar vizinhanças bidimensionais e ajustar modelos de regressão bivariada usando as observações que estão perto de cada ponto alvo no espaço bidimensional. Teoricamente, a mesma abordagem pode ser implementada em dimensões superiores, usando regressões lineares ajustadas a vizinhanças p-dimensionais. No entanto, a regressão local pode ter um desempenho ruim se \(p\) for muito maior que cerca de 3 ou 4, porque geralmente haverá muito poucas observações de treinamento próximas a \(x_0\). A regressão dos vizinhos mais próximos, discutida no Capítulo 3, sofre de um problema semelhante em altas dimensões.

7.7 - Modelos Aditivos Generalizados (GAMs)

Nas Seções 7.1–7.6, apresentamos várias abordagens para prever flexivelmente uma resposta \(Y\) com base em um único preditor \(X\). Essas abordagens podem ser vistas como extensões da regressão linear simples. Aqui exploramos o problema de prever flexivelmente \(Y\) com base em vários preditores, \(X_1, \ldots, X_p\). Isso equivale a uma extensão da regressão linear múltipla.

Os modelos aditivos generalizados (GAMs) fornecem uma estrutura geral para estender um modelo linear padrão, permitindo funções não lineares de cada uma das variáveis, mantendo a aditividade. Assim como os modelos lineares, os GAMs podem ser aplicados tanto a respostas quantitativas quanto qualitativas. Primeiro examinamos os GAMs para uma resposta quantitativa na Seção 7.7.1, e depois para uma resposta qualitativa na Seção 7.7.2.

7.7.1 - GAMs para Problemas de Regressão

Uma maneira natural de estender o modelo de regressão linear múltipla \[ y_i = \beta_0 + \beta_1 x_{i1} + \beta_2 x_{i2} + \cdots + \beta_p x_{ip} + \epsilon_i \] para permitir relações não lineares entre cada característica e a resposta é substituir cada componente linear \(\beta_j x_{ij}\) por uma função (suave) não linear \(f_j (x_{ij})\). Então, escreveríamos o modelo como \[ y_i = \beta_0 + \sum_{j=1}^p f_j (x_{ij}) + \epsilon_i \\ = \beta_0 + f_1(x_{i1}) + f_2(x_{i2}) + \cdots + f_p(x_{ip}) + \epsilon_i. \]

Este é um exemplo de GAM. É chamado de modelo aditivo porque calculamos um \(f_j\) separado para cada \(X_j\), e depois somamos todas as suas contribuições.

Nas Seções 7.1–7.6, discutimos muitos métodos para ajustar funções a uma única variável. A beleza dos GAMs é que podemos usar esses métodos como blocos de construção para ajustar um modelo aditivo. De fato, para a maioria dos métodos que vimos até agora neste capítulo, isso pode ser feito de forma bastante trivial. Pegue, por exemplo, splines naturais, e considere a tarefa de ajustar o modelo \[ \text{wage} = \beta_0 + f_1(\text{year}) + f_2(\text{age}) + f_3(\text{education}) + \epsilon \] nos dados de Wage. Aqui year e age são variáveis quantitativas, enquanto a variável education é qualitativa com cinco níveis: <HS, HS, <Coll, Coll, >Coll, referindo-se à quantidade de educação de ensino médio ou superior que um indivíduo completou. Ajustamos as duas primeiras funções usando splines naturais. Ajustamos a terceira função usando uma constante separada para cada nível, através da abordagem usual de variável dummy da Seção 3.3.1.

A Figura 7.11 mostra os resultados do ajuste do modelo (7.16) usando mínimos quadrados. Isso é fácil de fazer, já que, como discutido na Seção 7.4, splines naturais podem ser construídos usando um conjunto de funções base escolhidas adequadamente. Portanto, todo o modelo é apenas uma grande regressão em variáveis de base spline e variáveis dummy, todas agrupadas em uma grande matriz de regressão.

A Figura 7.11 pode ser facilmente interpretada. O painel à esquerda indica que, mantendo age e education fixos, wage tende a aumentar ligeiramente com year; isso pode ser devido à inflação. O painel central indica que, mantendo education e year fixos, wage tende a ser mais alto para valores intermediários de age e mais baixo para os muito jovens e muito velhos. Ajustar um GAM com uma spline de suavização não é tão simples quanto ajustar um GAM com uma spline natural, já que no caso de splines de suavização, mínimos quadrados não podem ser usados. No entanto, softwares padrão, como a função gam() em R, podem ser usados para ajustar GAMs usando splines de suavização, através de uma abordagem conhecida como backfitting. Este método ajusta um modelo envolvendo múltiplos preditores atualizando repetidamente o ajuste para cada preditor por sua vez, mantendo os outros fixos. A beleza dessa abordagem é que cada vez que atualizamos uma função, simplesmente aplicamos o método de ajuste para essa variável a um resíduo parcial.

As funções ajustadas nas Figuras 7.11 e 7.12 são bastante semelhantes. Na maioria das situações, as diferenças nos GAMs obtidos usando splines de suavização versus splines naturais são pequenas.

Não precisamos usar splines como blocos de construção para GAMs: podemos usar também regressão local, regressão polinomial ou qualquer combinação das abordagens vistas anteriormente neste capítulo para criar um GAM. Os GAMs são investigados com mais detalhes no laboratório no final deste capítulo.

Prós e Contras dos GAMs

Antes de prosseguirmos, vamos resumir as vantagens e limitações de um GAM.

▲ Os GAMs nos permitem ajustar um \(f_j\) não linear a cada \(X_j\), de modo que podemos modelar automaticamente relações não lineares que a regressão linear padrão não detectaria. Isso significa que não precisamos tentar manualmente muitas transformações diferentes em cada variável individualmente.

▲ Os ajustes não lineares podem potencialmente fazer previsões mais precisas para a resposta \(Y\).

▲ Como o modelo é aditivo, podemos examinar o efeito de cada \(X_j\) sobre \(Y\) individualmente, mantendo todas as outras variáveis fixas.

▲ A suavidade da função \(f_j\) para a variável \(X_j\) pode ser resumida via graus de liberdade.

◆ A principal limitação dos GAMs é que o modelo é restrito a ser aditivo. Com muitas variáveis, interações importantes podem ser perdidas. No entanto, assim como na regressão linear, podemos adicionar manualmente termos de interação ao modelo GAM incluindo preditores adicionais da forma \(X_j \times X_k\). Além disso, podemos adicionar funções de interação de baixa dimensão da forma \(f_{jk}(X_j, X_k)\) no modelo; esses termos podem ser ajustados usando suavizadores bidimensionais, como a regressão local, ou splines bidimensionais (não cobertos aqui).

Para modelos totalmente gerais, precisamos buscar abordagens ainda mais flexíveis, como florestas aleatórias e boosting, descritos no Capítulo 8. Os GAMs fornecem um compromisso útil entre modelos lineares e modelos totalmente não paramétricos.

7.7.2 - GAMs para Problemas de Classificação

Os GAMs também podem ser usados em situações onde \(Y\) é qualitativo. Para simplificar, aqui assumimos que \(Y\) assume valores 0 ou 1, e seja \(p(X) = \text{Pr}(Y = 1|X)\) a probabilidade condicional (dado os preditores) de que a resposta seja igual a um. Relembre o modelo de regressão logística (4.6): \[ \log \left( \frac{p(X)}{1 - p(X)} \right) = \beta_0 + \beta_1 X_1 + \beta_2 X_2 + \cdots + \beta_p X_p. \]

O lado esquerdo é o logaritmo das chances de \(\text{P}(Y = 1|X)\) versus \(\text{P}(Y = 0|X)\), que (7.17) representa como uma função linear dos preditores. Uma maneira natural de estender (7.17) para permitir relações não lineares é usar o modelo \[ \log \left( \frac{p(X)}{1 - p(X)} \right) = \beta_0 + f_1(X_1) + f_2(X_2) + \cdots + f_p(X_p). \]

A Equação 7.18 é um GAM de regressão logística. Ele possui todos os mesmos prós e contras discutidos na seção anterior para respostas quantitativas.

Ajustamos um GAM aos dados de Wage para prever a probabilidade de que a renda de um indivíduo exceda 250,000 por ano. O GAM que ajustamos assume a forma

\[ \log \left( \frac{p(X)}{1 - p(X)} \right) = \beta_0 + \beta_1 \times \text{year} + f_2(\text{age}) + f_3(\text{education}), \]

onde

\[ p(X) = \text{Pr}(\text{wage} > 250|\text{year}, \text{age}, \text{education}). \]

Mais uma vez, \(f_2\) é ajustado usando uma spline de suavização com cinco graus de liberdade, e \(f_3\) é ajustado como uma função em degraus, criando variáveis dummy para cada um dos níveis de education. O ajuste resultante é mostrado na Figura 7.13. O último painel parece suspeito, com intervalos de confiança muito amplos para o nível <HS. De fato, nenhum valor de resposta é igual a um para essa categoria: nenhum indivíduo com menos do que um diploma de ensino médio ganha mais de $250,000 por ano. Portanto, re-ajustamos o GAM, excluindo os indivíduos com menos do que um diploma de ensino médio. O modelo resultante é mostrado na Figura 7.14. Assim como nas Figuras 7.11 e 7.12, todos os três painéis têm escalas verticais semelhantes. Isso nos permite avaliar visualmente as contribuições relativas de cada uma das variáveis. Observamos que age e education têm um efeito muito maior do que year na probabilidade de ser um alto ganhador.

No entanto, calcular os intervalos de confiança é um pouco mais complicado do que no caso da regressão linear. O tipo de previsão padrão para um modelo glm() é type = "link", que é o que usamos aqui. Isso significa que obtemos previsões para o logito, ou log-odds: ou seja, ajustamos um modelo da forma \[ \log \left( \frac{\text{Pr}(Y = 1|X)}{1 - \text{Pr}(Y = 1|X)} \right) = X\beta, \] e as previsões fornecidas são da forma \(X\hat{\beta}\). Para obter intervalos de confiança para \(\text{Pr}(Y = 1|X)\), usamos a transformação \[ \text{Pr}(Y = 1|X) = \frac{\exp(X\beta)}{1 + \exp(X\beta)}. \]
