6 - Seleção de Modelos Lineares e Regularização

No contexto de regressão, o modelo linear padrão \[Y = \beta_0 + \beta_1X_1 + \cdots + \beta_pX_p + \epsilon\] é comumente usado para descrever a relação entre uma resposta \(Y\) e um conjunto de variáveis \(X_1, X_2, ..., X_p\). Vimos no Capítulo 3 que esse modelo é tipicamente ajustado usando mínimos quadrados.

Nos capítulos seguintes, consideramos algumas abordagens para estender a estrutura do modelo linear. No Capítulo 7, generalizamos (6.1) para acomodar relações não lineares, mas ainda aditivas, enquanto nos Capítulos 8 e 10 consideramos modelos não lineares ainda mais gerais. No entanto, o modelo linear tem vantagens distintas em termos de inferência e, em problemas do mundo real, é frequentemente surpreendentemente competitivo em relação a métodos não lineares. Portanto, antes de nos movermos para o mundo não linear, discutimos neste capítulo algumas maneiras pelas quais o modelo linear simples pode ser melhorado, substituindo o ajuste de mínimos quadrados por alguns procedimentos de ajuste alternativos.

Por que poderíamos querer usar outro procedimento de ajuste em vez de mínimos quadrados? Como veremos, procedimentos de ajuste alternativos podem proporcionar melhor precisão de previsão e interpretabilidade do modelo.

  • Precisão de Previsão: Desde que a verdadeira relação entre a resposta e os preditores seja aproximadamente linear, as estimativas de mínimos quadrados terão baixo viés. Se \(n \gg p\)—ou seja, se \(n\), o número de observações, for muito maior que \(p\), o número de variáveis—então as estimativas de mínimos quadrados tendem a ter baixa variância, e, portanto, funcionarão bem em observações de teste. No entanto, se \(n\) não for muito maior que \(p\), pode haver muita variabilidade no ajuste de mínimos quadrados, resultando em sobreajuste e, consequentemente, em previsões pobres em observações futuras não usadas no treinamento do modelo. E se \(p > n\), então não há mais uma estimativa única de coeficiente de mínimos quadrados: há infinitas soluções. Cada uma dessas soluções de mínimos quadrados dá erro zero nos dados de treinamento, mas tipicamente desempenho muito ruim no conjunto de teste devido à variância extremamente alta. Ao restringir ou encolher os coeficientes estimados, podemos frequentemente reduzir substancialmente a variância ao custo de um aumento negligenciável no viés. Isso pode levar a melhorias substanciais na precisão com a qual podemos prever a resposta para observações não usadas no treinamento do modelo.

  • Interpretabilidade do Modelo: Muitas vezes, algumas ou muitas das variáveis usadas em um modelo de regressão múltipla não estão de fato associadas à resposta. Incluir tais variáveis irrelevantes leva a uma complexidade desnecessária no modelo resultante. Ao remover essas variáveis—ou seja, definindo as estimativas dos coeficientes correspondentes como zero—podemos obter um modelo que é mais facilmente interpretado. Agora, os mínimos quadrados são extremamente improváveis de fornecer quaisquer estimativas de coeficientes que sejam exatamente zero. Neste capítulo, vemos algumas abordagens para realizar automaticamente a seleção de características ou seleção de variáveis—ou seja, para excluir variáveis irrelevantes de um modelo de regressão múltipla.

Existem muitas alternativas, tanto clássicas quanto modernas, para usar mínimos quadrados para ajustar (6.1). Neste capítulo, discutimos três classes importantes de métodos.

  • Seleção de Subconjunto: Esta abordagem envolve identificar um subconjunto dos \(p\) preditores que acreditamos estar relacionados à resposta. Em seguida, ajustamos um modelo usando mínimos quadrados no conjunto reduzido de variáveis.

  • Encolhimento: Esta abordagem envolve ajustar um modelo envolvendo todos os \(p\) preditores. No entanto, os coeficientes estimados são encolhidos em direção a zero em relação às estimativas de mínimos quadrados. Este encolhimento (também conhecido como regularização) tem o efeito de reduzir a variância. Dependendo do tipo de encolhimento realizado, alguns dos coeficientes podem ser estimados exatamente como zero. Portanto, os métodos de encolhimento também podem realizar a seleção de variáveis.

  • Redução de Dimensão: Esta abordagem envolve projetar os \(p\) preditores em um subespaço de dimensão \(M\), onde \(M < p\). Isso é alcançado ao calcular \(M\) diferentes combinações lineares, ou projeções, das variáveis. Em seguida, essas \(M\) projeções são usadas como preditores para ajustar um modelo de regressão linear por mínimos quadrados.

Nas seções seguintes, descrevemos cada uma dessas abordagens em mais detalhes, junto com suas vantagens e desvantagens. Embora este capítulo descreva extensões e modificações para o modelo linear de regressão visto no Capítulo 3, os mesmos conceitos se aplicam a outros métodos, como os modelos de classificação vistos no Capítulo 4.

6.1 - Seleção de Subconjuntos

Nesta seção, consideramos alguns métodos para selecionar subconjuntos de preditores. Esses incluem os procedimentos de seleção de melhor subconjunto e seleção de modelo stepwise.

6.1.1 - Seleção do Melhor Subconjunto

Para realizar a seleção do melhor subconjunto, ajustamos uma regressão de mínimos quadrados separada para cada combinação possível dos \(p\) preditores. Isto é, ajustamos todos os \(p\) modelos que contêm exatamente um preditor, todos os \(\binom{p}{2}\) modelos que contêm exatamente dois preditores, e assim por diante. Em seguida, analisamos todos os modelos resultantes, com o objetivo de identificar aquele que é o melhor.

O problema de selecionar o melhor modelo dentre as \(2^p\) possibilidades consideradas pela seleção do melhor subconjunto não é trivial. Isso é geralmente dividido em duas etapas, conforme descrito no Algoritmo 6.1.

Algoritmo 6.1 Seleção do melhor subconjunto

  1. Deixe \(M_0\) denotar o modelo nulo, que não contém preditores. Este modelo simplesmente prevê a média amostral para cada observação.

  2. Para \(k = 1, 2, ..., p\): (a) Ajuste todos os \(\binom{p}{k}\) modelos que contêm exatamente \(k\) preditores. (b) Escolha o melhor entre esses \(\binom{p}{k}\) modelos e chame-o de \(M_k\). Aqui, melhor é definido como tendo o menor RSS, ou equivalente, o maior \(R^2\).

  3. Selecione um único melhor modelo entre \(M_0, ..., M_p\) usando o erro de previsão em um conjunto de validação, \(C_p\) (AIC), BIC, ou \(R^2\) ajustado. Ou use o método de validação cruzada.

No Algoritmo 6.1, a Etapa 2 identifica o melhor modelo (nos dados de treinamento) para cada tamanho de subconjunto, a fim de reduzir o problema de \(2^p\) modelos possíveis para \(p + 1\) modelos possíveis. Na Figura 6.1, esses modelos formam a fronteira inferior representada em vermelho.

Agora, para selecionar um único melhor modelo, devemos simplesmente escolher entre essas \(p + 1\) opções. Essa tarefa deve ser realizada com cuidado, pois o RSS desses \(p + 1\) modelos diminui monotonamente e o \(R^2\) aumenta monotonamente à medida que o número de variáveis incluídas nos modelos aumenta. Portanto, se usarmos essas estatísticas para selecionar o melhor modelo, sempre terminaremos com um modelo envolvendo todas as variáveis. O problema é que um RSS baixo ou um \(R^2\) alto indica um modelo com baixo erro de treinamento, enquanto desejamos escolher um modelo que tenha baixo erro de teste. (Como mostrado no Capítulo 2 nas Figuras 2.9–2.11, o erro de treinamento tende a ser significativamente menor do que o erro de teste, e um baixo erro de treinamento de forma alguma garante um baixo erro de teste.) Portanto, na Etapa 3, usamos o erro em um conjunto de validação, \(C_p\), BIC ou \(R^2\) ajustado para selecionar entre \(M_0, M_1, ..., M_p\). Se a validação cruzada for usada para selecionar o melhor modelo, então a Etapa 2 é repetida em cada conjunto de treinamento, e os erros de validação são calculados para selecionar o melhor valor de \(k\). Em seguida, o modelo \(M_k\) ajustado no conjunto de treinamento completo é entregue para o \(k\) escolhido. Essas abordagens são discutidas na Seção 6.1.3.

Uma aplicação da seleção do melhor subconjunto é mostrada na Figura 6.1. Cada ponto plotado corresponde a um modelo de regressão de mínimos quadrados ajustado usando um subconjunto diferente dos 10 preditores no conjunto de dados Credit, discutido no Capítulo 3. Aqui, a variável region é uma variável qualitativa de três níveis e, portanto, é representada por duas variáveis dummy, que são selecionadas separadamente neste caso. Assim, há um total de 11 variáveis possíveis que podem ser incluídas no modelo. Plotamos as estatísticas RSS e \(R^2\) para cada modelo, como uma função do número de variáveis. As curvas vermelhas conectam os melhores modelos para cada tamanho de modelo, de acordo com RSS ou \(R^2\). A figura mostra que, como esperado, essas quantidades melhoram à medida que o número de variáveis aumenta; no entanto, a partir do modelo de três variáveis, há pouca melhoria no RSS e \(R^2\) como resultado da inclusão de preditores adicionais.

Embora tenhamos apresentado a seleção do melhor subconjunto aqui para regressão de mínimos quadrados, as mesmas ideias se aplicam a outros tipos de modelos, como a regressão logística. No caso da regressão logística, em vez de ordenar os modelos por RSS na Etapa 2 do Algoritmo 6.1, usamos o desvio, uma medida que desempenha o papel do RSS para uma classe mais ampla de modelos. O desvio é igual a menos duas vezes o log-verossimilhança maximizada; quanto menor o desvio, melhor o ajuste.

Embora a seleção do melhor subconjunto seja uma abordagem simples e conceitualmente atraente, ela sofre de limitações computacionais. O número de modelos possíveis que devem ser considerados cresce rapidamente à medida que \(p\) aumenta. Em geral, há \(2^p\) modelos que envolvem subconjuntos dos \(p\) preditores. Então, se \(p = 10\), há aproximadamente 1.000 modelos possíveis a serem considerados, e se \(p = 20\), há mais de um milhão de possibilidades! Consequentemente, a seleção do melhor subconjunto torna-se inviável computacionalmente para valores de \(p\) maiores que cerca de 40, mesmo com computadores modernos extremamente rápidos. Existem atalhos computacionais—chamadas técnicas de branch-and-bound—para eliminar algumas escolhas, mas essas têm suas limitações à medida que \(p\) aumenta. Eles também só funcionam para regressão linear de mínimos quadrados. Apresentamos alternativas computacionalmente eficientes à seleção do melhor subconjunto a seguir.

6.1.2 - Seleção Stepwise

Por razões computacionais, a seleção do melhor subconjunto não pode ser aplicada quando \(p\) é muito grande. A seleção do melhor subconjunto também pode sofrer problemas estatísticos quando \(p\) é grande. Quanto maior o espaço de busca, maior a chance de encontrar modelos que parecem bons nos dados de treinamento, embora possam não ter qualquer poder preditivo em dados futuros. Assim, um espaço de busca enorme pode levar ao sobreajuste e alta variância nas estimativas dos coeficientes.

Por ambas as razões, métodos stepwise, que exploram um conjunto de modelos muito mais restrito, são alternativas atraentes à seleção do melhor subconjunto.

Seleção Stepwise Progressiva

A seleção stepwise progressiva é uma alternativa computacionalmente eficiente à seleção do melhor subconjunto. Enquanto o procedimento de seleção do melhor subconjunto considera todos os \(2^p\) modelos possíveis contendo subconjuntos dos \(p\) preditores, a seleção stepwise progressiva considera um conjunto muito menor de modelos. A seleção stepwise progressiva começa com um modelo sem preditores e, em seguida, adiciona preditores ao modelo, um de cada vez, até que todos os preditores estejam no modelo. Em particular, a cada passo, a variável que proporciona a maior melhoria adicional ao ajuste é adicionada ao modelo. Mais formalmente, o procedimento de seleção stepwise progressiva é dado no Algoritmo 6.2.

Algoritmo 6.2 Seleção stepwise progressiva

  1. Deixe \(M_0\) denotar o modelo nulo, que não contém preditores.

  2. Para \(k = 0, ..., p - 1\):

    1. (a) Considere todos os \(p - k\) modelos que aumentam os preditores em \(M_k\) com um preditor adicional.

    2. (b) Escolha o melhor entre esses \(p - k\) modelos e chame-o de \(M_{k+1}\). Aqui, melhor é definido como tendo o menor RSS ou o maior \(R^2\).

  3. Selecione um único melhor modelo entre \(M_0, ..., M_p\) usando o erro de previsão em um conjunto de validação, \(C_p\) (AIC), BIC, ou \(R^2\) ajustado. Ou use o método de validação cruzada.

Ao contrário da seleção do melhor subconjunto, que envolvia ajustar \(2^p\) modelos, a seleção stepwise progressiva envolve ajustar um modelo nulo, juntamente com \(p - k\) modelos na \(k\)-ésima iteração, para \(k = 0, ..., p - 1\). Isso resulta em um total de \(1 + \sum_{k=0}^{p-1}(p-k) = 1 + p(p + 1)/2\) modelos. Esta é uma diferença substancial: quando \(p = 20\), a seleção do melhor subconjunto requer o ajuste de 1.048.576 modelos, enquanto a seleção stepwise progressiva requer o ajuste de apenas 211 modelos.

Na Etapa 2(b) do Algoritmo 6.2, devemos identificar o melhor modelo dentre aqueles \(p - k\) que aumentam \(M_k\) com um preditor adicional. Podemos fazer isso simplesmente escolhendo o modelo com o menor RSS ou o maior \(R^2\). No entanto, na Etapa 3, devemos identificar o melhor modelo entre um conjunto de modelos com diferentes números de variáveis. Isso é mais desafiador e é discutido na Seção 6.1.3.

A vantagem computacional da seleção stepwise progressiva sobre a seleção do melhor subconjunto é clara. Embora a seleção stepwise progressiva tenda a ter um bom desempenho na prática, ela não é garantida para encontrar o melhor modelo possível entre todos os \(2^p\) modelos contendo subconjuntos dos \(p\) preditores. Por exemplo, suponha que em um determinado conjunto de dados com \(p = 3\) preditores, o melhor modelo possível de uma variável contenha \(X_1\), e o melhor modelo possível de duas variáveis contenha \(X_2\) e \(X_3\). Então, a seleção stepwise progressiva falhará em selecionar o melhor modelo possível de duas variáveis, porque \(M_1\) conterá \(X_1\), então \(M_2\) também deve conter \(X_1\) junto com uma variável adicional.

A Tabela 6.1, que mostra os primeiros quatro modelos selecionados para a seleção do melhor subconjunto e a seleção stepwise progressiva no conjunto de dados Credit, ilustra esse fenômeno. Tanto a seleção do melhor subconjunto quanto a seleção stepwise progressiva escolhem rating para o melhor modelo de uma variável e depois incluem income e student para os modelos de duas e três variáveis. No entanto, a seleção do melhor subconjunto substitui rating por cards no modelo de quatro variáveis, enquanto a seleção stepwise progressiva deve manter rating em seu modelo de quatro variáveis. Neste exemplo, a Figura 6.1 indica que não há muita diferença entre os modelos de três e quatro variáveis em termos de RSS, então qualquer um dos modelos de quatro variáveis será provavelmente adequado.

A seleção stepwise progressiva pode ser aplicada mesmo no cenário de alta dimensão onde \(n < p\); no entanto, nesse caso, é possível construir apenas submodelos \(M_0, ..., M_{n-1}\), uma vez que cada submodelo é ajustado usando mínimos quadrados, o que não produzirá uma solução única se \(p \ge n\).

Seleção Stepwise Regressiva

Assim como a seleção stepwise progressiva, a seleção stepwise regressiva oferece uma alternativa eficiente à seleção do melhor subconjunto. No entanto, ao contrário da seleção stepwise progressiva, ela começa com o modelo de mínimos quadrados completo contendo todos os \(p\) preditores e, em seguida, remove iterativamente o preditor menos útil, um de cada vez. Detalhes são dados no Algoritmo 6.3.

Algoritmo 6.3 Seleção stepwise regressiva

  1. Deixe \(M_p\) denotar o modelo completo, que contém todos os \(p\) preditores.

  2. Para \(k = p, p - 1, ..., 1\):

    1. (a) Considere todos os \(k\) modelos que contêm todos, exceto um dos preditores em \(M_k\), totalizando \(k - 1\) preditores.

    2. (b) Escolha o melhor entre esses \(k\) modelos e chame-o de \(M_{k-1}\). Aqui, melhor é definido como tendo o menor RSS ou o maior \(R^2\).

  3. Selecione um único melhor modelo entre \(M_0, ..., M_p\) usando o erro de previsão em um conjunto de validação, \(C_p\) (AIC), BIC ou \(R^2\) ajustado. Ou use o método de validação cruzada.

Assim como a seleção stepwise progressiva, a abordagem de seleção stepwise regressiva busca apenas 1 + \(p(p + 1)/2\) modelos e, portanto, pode ser aplicada em contextos onde \(p\) é muito grande para aplicar a seleção do melhor subconjunto. Também como a seleção stepwise progressiva, a seleção stepwise regressiva não é garantida para fornecer o melhor modelo contendo um subconjunto dos \(p\) preditores.

A seleção regressiva requer que o número de amostras \(n\) seja maior que o número de variáveis \(p\) (para que o modelo completo possa ser ajustado). Em contraste, a seleção stepwise progressiva pode ser usada mesmo quando \(n < p\), e assim é o único método viável de subconjunto quando \(p\) é muito grande.

Abordagens Híbridas

As abordagens de seleção do melhor subconjunto, stepwise progressiva e stepwise regressiva geralmente produzem modelos semelhantes, mas não idênticos. Como outra alternativa, versões híbridas das seleções stepwise progressiva e regressiva estão disponíveis, nas quais variáveis são adicionadas ao modelo sequencialmente, em analogia à seleção progressiva. No entanto, após adicionar cada nova variável, o método também pode remover quaisquer variáveis que não forneçam mais uma melhoria no ajuste do modelo. Tal abordagem tenta imitar mais de perto a seleção do melhor subconjunto, mantendo as vantagens computacionais das seleções stepwise progressiva e regressiva.

6.1.3 - Escolhendo o Modelo Ótimo

A seleção do melhor subconjunto, a seleção progressiva e a seleção regressiva resultam na criação de um conjunto de modelos, cada um contendo um subconjunto dos \(p\) preditores. Para aplicar esses métodos, precisamos de uma maneira de determinar qual desses modelos é o melhor. Como discutido na Seção 6.1.1, o modelo contendo todos os preditores sempre terá o menor RSS e o maior \(R^2\), pois essas quantidades estão relacionadas ao erro de treinamento. Em vez disso, desejamos escolher um modelo com baixo erro de teste. Como é evidente aqui, e como mostramos no Capítulo 2, o erro de treinamento pode ser uma estimativa ruim do erro de teste. Portanto, RSS e \(R^2\) não são adequados para selecionar o melhor modelo entre uma coleção de modelos com diferentes números de preditores.

Para selecionar o melhor modelo com respeito ao erro de teste, precisamos estimar esse erro de teste. Existem duas abordagens comuns:

  1. Podemos estimar indiretamente o erro de teste fazendo um ajuste no erro de treinamento para levar em conta o viés devido ao sobreajuste.
  2. Podemos estimar diretamente o erro de teste, usando uma abordagem de conjunto de validação ou uma abordagem de validação cruzada, como discutido no Capítulo 5.

Consideramos ambas as abordagens abaixo.

\(C_p\), AIC, BIC e \(R^2\) Ajustado

Mostramos no Capítulo 2 que o MSE do conjunto de treinamento é geralmente uma subestimação do MSE do conjunto de teste. (Lembre-se que \(MSE = \frac{RSS}{n}\).) Isso ocorre porque, ao ajustar um modelo aos dados de treinamento usando mínimos quadrados, especificamente estimamos os coeficientes de regressão de forma que o RSS de treinamento (mas não o RSS de teste) seja o menor possível. Em particular, o erro de treinamento diminuirá à medida que mais variáveis sejam incluídas no modelo, mas o erro de teste pode não diminuir. Portanto, RSS do conjunto de treinamento e \(R^2\) do conjunto de treinamento não podem ser usados para selecionar entre um conjunto de modelos com diferentes números de variáveis.

No entanto, várias técnicas para ajustar o erro de treinamento ao tamanho do modelo estão disponíveis. Essas abordagens podem ser usadas para selecionar entre um conjunto de modelos com diferentes números de variáveis. Agora consideramos quatro dessas abordagens: \(C_p\), critério de informação de Akaike (AIC), critério de informação Bayesiano (BIC) e \(R^2\) ajustado. A Figura 6.2 exibe \(C_p\), BIC e \(R^2\) ajustado para o melhor modelo de cada tamanho produzido pela seleção do melhor subconjunto no conjunto de dados Credit.

Para um modelo de mínimos quadrados ajustado contendo \(d\) preditores, a estimativa \(C_p\) do MSE do teste é calculada usando a equação \[ C_p = \frac{1}{n} \left( RSS + 2d\hat{\sigma}^2 \right), \] onde \(\hat{\sigma}^2\) é uma estimativa da variância do erro \(\epsilon\) associada a cada medição de resposta em (6.1). Tipicamente, \(\hat{\sigma}^2\) é estimada usando o modelo completo contendo todos os preditores. Essencialmente, a estatística \(C_p\) adiciona uma penalidade de \(2d\hat{\sigma}^2\) ao RSS de treinamento para ajustar ao fato de que o erro de treinamento tende a subestimar o erro de teste. Claramente, a penalidade aumenta à medida que o número de preditores no modelo aumenta; isso é destinado a ajustar a diminuição correspondente no RSS de treinamento. Embora esteja além do escopo deste livro, pode-se mostrar que, se \(\hat{\sigma}^2\) for uma estimativa não tendenciosa de \(\sigma^2\) em (6.2), então \(C_p\) é uma estimativa não tendenciosa do MSE do teste. Como consequência, a estatística \(C_p\) tende a assumir um valor pequeno para modelos com um baixo erro de teste, então ao determinar qual de um conjunto de modelos é o melhor, escolhemos o modelo com o menor valor de \(C_p\). Na Figura 6.2, \(C_p\) seleciona o modelo de seis variáveis contendo os preditores income, limit, rating, cards, age e student.

O critério AIC é definido para uma ampla classe de modelos ajustados por máxima verossimilhança. No caso do modelo (6.1) com erros Gaussianos, máxima verossimilhança e mínimos quadrados são a mesma coisa. Nesse caso, AIC é dado por \[ AIC = \frac{1}{n} \left( RSS + 2d\hat{\sigma}^2 \right), \] onde, para simplificar, omitimos constantes irrelevantes. Portanto, para modelos de mínimos quadrados, \(C_p\) e AIC são proporcionais entre si, e por isso apenas \(C_p\) é exibido na Figura 6.2.

BIC é derivado de um ponto de vista Bayesiano, mas acaba sendo semelhante ao \(C_p\) (e AIC) também. Para o modelo de mínimos quadrados com \(d\) preditores, o BIC é, desconsiderando constantes irrelevantes, dado por \[ BIC = \frac{1}{n} \left( RSS + \log(n)d\hat{\sigma}^2 \right). \]

Assim como \(C_p\), o BIC tende a assumir um valor pequeno para um modelo com baixo erro de teste, e assim geralmente selecionamos o modelo que tem o menor valor de BIC. Note que o BIC substitui os \(2d\hat{\sigma}^2\) usados pelo \(C_p\) por um termo \(\log(n)d\hat{\sigma}^2\), onde \(n\) é o número de observações. Como \(\log n > 2\) para qualquer \(n > 7\), a estatística BIC geralmente aplica uma penalidade maior aos modelos com muitas variáveis, e, portanto, resulta na seleção de modelos menores do que o \(C_p\). Na Figura 6.2, vemos que este é de fato o caso para o conjunto de dados Credit; BIC escolhe um modelo que contém apenas os quatro preditores income, limit, cards e student. Neste caso, as curvas são bastante planas e, portanto, não parece haver muita diferença em precisão entre os modelos de quatro e seis variáveis.

A estatística \(R^2\) ajustado é outra abordagem popular para selecionar entre um conjunto de modelos que contêm diferentes números de variáveis. Lembre-se do Capítulo 3 que o \(R^2\) usual é definido como \(1 - \frac{RSS}{TSS}\), onde \(TSS = \sum (y_i - \bar{y})^2\) é a soma total dos quadrados para a resposta. Como o RSS sempre diminui à medida que mais variáveis são adicionadas ao modelo, o \(R^2\) sempre aumenta à medida que mais variáveis são adicionadas. Para um modelo de mínimos quadrados com \(d\) variáveis, a estatística \(R^2\) ajustado é calculada como \[ R^2 \text{ ajustado} = 1 - \frac{RSS / (n - d - 1)}{TSS / (n - 1)}. \]

A intuição por trás do \(R^2\) ajustado é que, uma vez que todas as variáveis corretas tenham sido incluídas no modelo, adicionar variáveis de ruído adicionais levará a apenas uma pequena diminuição no RSS. Como adicionar variáveis de ruído leva a um aumento em \(d\), tais variáveis levarão a um aumento no termo \(RSS / (n - d - 1)\), e, consequentemente, a uma diminuição no \(R^2\) ajustado. Portanto, em teoria, o modelo com o maior \(R^2\) ajustado terá apenas variáveis corretas e nenhuma variável de ruído. Ao contrário da estatística \(R^2\), a estatística \(R^2\) ajustado paga um preço pela inclusão de variáveis desnecessárias no modelo. A Figura 6.2 exibe o \(R^2\) ajustado para o conjunto de dados Credit. Usando essa estatística, resulta na seleção de um modelo que contém sete variáveis, adicionando own ao modelo selecionado por \(C_p\) e AIC.

\(C_p\), AIC e BIC têm justificativas teóricas rigorosas que estão além do escopo deste livro. Essas justificativas dependem de argumentos assintóticos (cenários onde o tamanho da amostra \(n\) é muito grande). Apesar de sua popularidade e mesmo sendo bastante intuitivo, o \(R^2\) ajustado não é tão bem fundamentado na teoria estatística quanto AIC, BIC e \(C_p\). Todas essas medidas são simples de usar e calcular. Aqui, apresentamos suas fórmulas no caso de um modelo linear ajustado usando mínimos quadrados; no entanto, AIC e BIC também podem ser definidos para tipos mais gerais de modelos.

Validação e Validação Cruzada

Como alternativa às abordagens discutidas anteriormente, podemos estimar diretamente o erro de teste usando os métodos de conjunto de validação e validação cruzada discutidos no Capítulo 5. Podemos calcular o erro do conjunto de validação ou o erro de validação cruzada para cada modelo em consideração e, em seguida, selecionar o modelo para o qual o erro de teste estimado resultante é o menor. Esse procedimento tem uma vantagem em relação ao AIC, BIC, \(C_p\) e \(R^2\) ajustado, pois fornece uma estimativa direta do erro de teste e faz menos suposições sobre o modelo subjacente verdadeiro. Ele também pode ser usado em uma ampla gama de tarefas de seleção de modelos, mesmo em casos onde é difícil determinar os graus de liberdade do modelo (por exemplo, o número de preditores no modelo) ou difícil estimar a variância do erro \(\sigma^2\). Note que, quando a validação cruzada é usada, a sequência de modelos \(M_k\) nos Algoritmos 6.1–6.3 é determinada separadamente para cada dobra de treinamento, e os erros de validação são calculados para cada tamanho de modelo \(k\). Isso significa, por exemplo, com regressão do melhor subconjunto, que \(M_k\), o melhor subconjunto de tamanho \(k\), pode diferir entre as dobras. Uma vez escolhido o melhor tamanho \(k\), encontramos o melhor modelo desse tamanho no conjunto de dados completo.

No passado, realizar validação cruzada era proibitivamente caro em termos computacionais para muitos problemas com grande \(p\) e/ou grande \(n\), e, portanto, AIC, BIC, \(C_p\) e \(R^2\) ajustado eram abordagens mais atraentes para escolher entre um conjunto de modelos. No entanto, hoje em dia, com computadores rápidos, os cálculos necessários para realizar validação cruzada quase nunca são um problema. Assim, a validação cruzada é uma abordagem muito atraente para selecionar entre vários modelos em consideração.

A Figura 6.3 exibe, como uma função de \(d\), o BIC, os erros do conjunto de validação e os erros de validação cruzada nos dados Credit, para o melhor modelo de \(d\) variáveis. Os erros de validação foram calculados selecionando aleatoriamente três quartos das observações como conjunto de treinamento e o restante como conjunto de validação. Os erros de validação cruzada foram calculados usando \(k = 10\) dobras. Nesse caso, os métodos de validação e validação cruzada resultam ambos em um modelo de seis variáveis. No entanto, as três abordagens sugerem que os modelos de quatro, cinco e seis variáveis são aproximadamente equivalentes em termos de seus erros de teste.

De fato, as curvas de erro de teste estimado exibidas nos painéis central e direito da Figura 6.3 são bastante planas. Embora um modelo de três variáveis claramente tenha um erro de teste estimado menor do que um modelo de duas variáveis, os erros de teste estimados dos modelos de 3 a 11 variáveis são bastante semelhantes. Além disso, se repetirmos a abordagem do conjunto de validação usando uma divisão diferente dos dados em um conjunto de treinamento e um conjunto de validação, ou se repetirmos a validação cruzada usando um conjunto diferente de dobras de validação cruzada, então o modelo preciso com o menor erro de teste estimado certamente mudaria. Nesse cenário, podemos selecionar um modelo usando a regra do erro padrão. Primeiro, calculamos o erro padrão do MSE de teste estimado para cada tamanho de modelo e, em seguida, selecionamos o menor modelo para o qual o erro de teste estimado está dentro de um erro padrão do ponto mais baixo na curva. A justificativa aqui é que, se um conjunto de modelos parece ser mais ou menos igualmente bom, podemos muito bem escolher o modelo mais simples—isto é, o modelo com o menor número de preditores. Nesse caso, aplicar a regra do erro padrão ao conjunto de validação ou à abordagem de validação cruzada leva à seleção do modelo de três variáveis.

6.2 - Métodos de Encolhimento

Os métodos de seleção de subconjuntos descritos na Seção 6.1 envolvem o uso de mínimos quadrados para ajustar um modelo linear que contém um subconjunto dos preditores. Como alternativa, podemos ajustar um modelo contendo todos os \(p\) preditores usando uma técnica que constrange ou regulariza as estimativas dos coeficientes, ou, de forma equivalente, que reduz as estimativas dos coeficientes em direção a zero. Pode não ser imediatamente óbvio por que tal restrição deveria melhorar o ajuste, mas resulta que reduzir as estimativas dos coeficientes pode reduzir significativamente sua variância. As duas técnicas mais conhecidas para reduzir os coeficientes de regressão em direção a zero são a regressão ridge e o lasso.

6.2.1 - Regressão Ridge

Lembre-se do Capítulo 3 que o procedimento de ajuste de mínimos quadrados estima \(\beta_0, \beta_1, ..., \beta_p\) usando os valores que minimizam \[ RSS = \sum_{i=1}^{n} \left( y_i - \beta_0 - \sum_{j=1}^{p} \beta_j x_{ij} \right)^2. \]

A regressão ridge é muito semelhante aos mínimos quadrados, exceto que os coeficientes são estimados minimizando uma quantidade ligeiramente diferente. Em particular, as estimativas dos coeficientes da regressão ridge \(\hat{\beta}^R\) são os valores que minimizam \[ \sum_{i=1}^{n} \left( y_i - \beta_0 - \sum_{j=1}^{p} \beta_j x_{ij} \right)^2 + \lambda \sum_{j=1}^{p} \beta_j^2 = RSS + \lambda \sum_{j=1}^{p} \beta_j^2, \] onde \(\lambda \ge 0\) é um parâmetro de ajuste, a ser determinado separadamente. A Equação 6.5 equilibra dois critérios diferentes. Assim como nos mínimos quadrados, a regressão ridge busca estimativas de coeficientes que ajustem bem os dados, tornando o RSS pequeno. No entanto, o segundo termo, \(\lambda \sum \beta_j^2\), chamado de penalidade de shrinkage, é pequeno quando \(\beta_1, ..., \beta_p\) estão próximos de zero, e assim tem o efeito de reduzir as estimativas de \(\beta_j\) em direção a zero. O parâmetro de ajuste \(\lambda\) serve para controlar o impacto relativo desses dois termos nas estimativas dos coeficientes de regressão. Quando \(\lambda = 0\), o termo de penalidade não tem efeito, e a regressão ridge produzirá as estimativas de mínimos quadrados. No entanto, à medida que \(\lambda \to \infty\), o impacto da penalidade de shrinkage cresce, e as estimativas dos coeficientes da regressão ridge se aproximarão de zero. Ao contrário dos mínimos quadrados, que geram apenas um conjunto de estimativas de coeficientes, a regressão ridge produzirá um conjunto diferente de estimativas de coeficientes, \(\hat{\beta}^R_{\lambda}\), para cada valor de \(\lambda\). Selecionar um bom valor para \(\lambda\) é crucial; adiamos essa discussão para a Seção 6.2.3, onde usaremos a validação cruzada.

Observe que na Equação 6.5, a penalidade de shrinkage é aplicada a \(\beta_1, ..., \beta_p\), mas não ao intercepto \(\beta_0\). Queremos reduzir a associação estimada de cada variável com a resposta; no entanto, não queremos reduzir o intercepto, que é simplesmente uma medida do valor médio da resposta quando \(x_{i1} = x_{i2} = ... = x_{ip} = 0\). Se assumirmos que as variáveis—isto é, as colunas da matriz de dados \(X\)—foram centradas para ter média zero antes de a regressão ridge ser realizada, então o intercepto estimado terá a forma \(\hat{\beta}_0 = \bar{y} = \sum_{i=1}^{n} y_i/n\).

Uma Aplicação aos Dados Credit

Na Figura 6.4, as estimativas dos coeficientes da regressão ridge para o conjunto de dados Credit são exibidas. No painel da esquerda, cada curva corresponde à estimativa do coeficiente da regressão ridge para uma das dez variáveis, plotada como uma função de \(\lambda\). Por exemplo, a linha preta sólida representa a estimativa da regressão ridge para o coeficiente de income, conforme \(\lambda\) é variado. No extremo esquerdo do gráfico, \(\lambda\) é essencialmente zero, e, portanto, as estimativas dos coeficientes da regressão ridge correspondentes são as mesmas que as estimativas usuais dos mínimos quadrados. Mas, à medida que \(\lambda\) aumenta, as estimativas dos coeficientes da regressão ridge se aproximam de zero. Quando \(\lambda\) é extremamente grande, todas as estimativas dos coeficientes da regressão ridge são basicamente zero; isso corresponde ao modelo nulo que não contém preditores. Neste gráfico, as variáveis income, limit, rating e student são exibidas em cores distintas, pois essas variáveis tendem a ter as maiores estimativas de coeficientes de longe. Enquanto as estimativas dos coeficientes da regressão ridge tendem a diminuir no agregado à medida que \(\lambda\) aumenta, coeficientes individuais, como rating e income, podem ocasionalmente aumentar conforme \(\lambda\) aumenta.

O painel da direita da Figura 6.4 exibe as mesmas estimativas dos coeficientes da regressão ridge que o painel da esquerda, mas em vez de exibir \(\lambda\) no eixo x, agora exibimos \(\|\hat{\beta}^R_{\lambda}\|_2/\|\hat{\beta}\|_2\), onde \(\hat{\beta}\) denota o vetor das estimativas dos coeficientes de mínimos quadrados. A notação \(\|\beta\|_2\) denota a norma \(\ell_2\) de um vetor, e é definida como \(\|\beta\|_2 = \sqrt{\sum_{j=1}^{p} \beta_j^2}\). Ela mede a distância de \(\beta\) a zero. À medida que \(\lambda\) aumenta, a norma \(\ell_2\) de \(\hat{\beta}^R_{\lambda}\) sempre diminuirá, assim como \(\|\hat{\beta}^R_{\lambda}\|_2/\|\hat{\beta}\|_2\). Esta última quantidade varia de 1 (quando \(\lambda = 0\), caso em que a estimativa do coeficiente da regressão ridge é a mesma que a estimativa dos mínimos quadrados, e assim suas normas \(\ell_2\) são as mesmas) a 0 (quando \(\lambda = \infty\), caso em que a estimativa do coeficiente da regressão ridge é um vetor de zeros, com norma \(\ell_2\) igual a zero). Portanto, podemos pensar no eixo x no painel da direita da Figura 6.4 como a quantidade que as estimativas dos coeficientes da regressão ridge foram reduzidas em direção a zero; um valor pequeno indica que elas foram reduzidas muito próximas a zero.

As estimativas dos coeficientes dos mínimos quadrados discutidas no Capítulo 3 são invariante a escala: multiplicar \(X_j\) por uma constante \(c\) simplesmente leva a uma escala das estimativas dos coeficientes dos mínimos quadrados por um fator de \(1/c\). Em outras palavras, independentemente de como o \(j\)-ésimo preditor é escalado, \(X_j\hat{\beta}_j\) permanecerá o mesmo. Em contraste, as estimativas dos coeficientes da regressão ridge podem mudar substancialmente ao multiplicar um dado preditor por uma constante. Por exemplo, considere a variável income, que é medida em dólares. Poderíamos razoavelmente ter medido income em milhares de dólares, o que resultaria em uma redução nos valores observados de income por um fator de 1.000. Agora, devido ao termo da soma dos quadrados dos coeficientes na formulação da regressão ridge (6.5), tal mudança de escala não causará simplesmente que a estimativa do coeficiente da regressão ridge para income mude por um fator de 1.000. Em outras palavras, \(X_j\hat{\beta}^R_{j,\lambda}\) dependerá não apenas do valor de \(\lambda\), mas também da escala do \(j\)-ésimo preditor. De fato, o valor de \(X_j\hat{\beta}^R_{j,\lambda}\) pode até depender da escala dos outros preditores! Portanto, é melhor aplicar a regressão ridge após padronizar os preditores, usando a fórmula \[ \tilde{x}_{ij} = \frac{x_{ij}}{\sqrt{\frac{1}{n}\sum_{i=1}^{n}(x_{ij} - \bar{x}_j)^2}}, \] para que todos estejam na mesma escala. Em (6.6), o denominador é o desvio padrão estimado do \(j\)-ésimo preditor. Consequentemente, todos os preditores padronizados terão um desvio padrão de um. Como resultado, o ajuste final não dependerá da escala na qual os preditores são medidos. Na Figura 6.4, o eixo y exibe as estimativas dos coeficientes padronizados da regressão ridge—isto é, as estimativas dos coeficientes resultantes da realização da regressão ridge usando preditores padronizados.

Por Que a Regressão Ridge é Melhor que os Mínimos Quadrados?

A vantagem da regressão ridge sobre os mínimos quadrados está enraizada na troca entre viés e variância. À medida que \(\lambda\) aumenta, a flexibilidade do ajuste da regressão ridge diminui, levando a uma diminuição da variância, mas a um aumento do viés. Isso é ilustrado no painel esquerdo da Figura 6.5, usando um conjunto de dados simulado contendo \(p = 45\) preditores e \(n = 50\) observações. A curva verde no painel esquerdo da Figura 6.5 mostra a variância das previsões da regressão ridge como uma função de \(\lambda\). Nas estimativas dos coeficientes de mínimos quadrados, que correspondem à regressão ridge com \(\lambda = 0\), a variância é alta, mas não há viés. Porém, à medida que \(\lambda\) aumenta, a redução das estimativas dos coeficientes ridge leva a uma redução substancial na variância das previsões, à custa de um leve aumento no viés. Lembre-se de que o erro quadrático médio de teste (MSE), plotado em roxo, está intimamente relacionado à variância mais o viés quadrado. Para valores de \(\lambda\) até cerca de 10, a variância diminui rapidamente, com muito pouco aumento no viés, plotado em preto. Consequentemente, o MSE cai consideravelmente à medida que \(\lambda\) aumenta de 0 para 10. Além desse ponto, a diminuição da variância devido ao aumento de \(\lambda\) desacelera, e a redução dos coeficientes faz com que sejam significativamente subestimados, resultando em um grande aumento no viés. O MSE mínimo é alcançado em aproximadamente \(\lambda = 30\). Curiosamente, devido à sua alta variância, o MSE associado ao ajuste de mínimos quadrados, quando \(\lambda = 0\), é quase tão alto quanto o do modelo nulo, no qual todas as estimativas dos coeficientes são zero, quando \(\lambda = \infty\). No entanto, para um valor intermediário de \(\lambda\), o MSE é consideravelmente menor.

O painel direito da Figura 6.5 exibe as mesmas curvas do painel esquerdo, desta vez plotadas contra a norma \(\ell_2\) das estimativas dos coeficientes da regressão ridge dividida pela norma \(\ell_2\) das estimativas de mínimos quadrados. Agora, à medida que nos movemos da esquerda para a direita, os ajustes tornam-se mais flexíveis, e assim o viés diminui e a variância aumenta.

Em geral, em situações onde a relação entre a resposta e os preditores é próxima de linear, as estimativas de mínimos quadrados terão baixo viés, mas podem ter alta variância. Isso significa que uma pequena mudança nos dados de treinamento pode causar uma grande mudança nas estimativas dos coeficientes de mínimos quadrados. Em particular, quando o número de variáveis \(p\) é quase tão grande quanto o número de observações \(n\), como no exemplo da Figura 6.5, as estimativas de mínimos quadrados serão extremamente variáveis. E se \(p > n\), então as estimativas de mínimos quadrados nem mesmo têm uma solução única, enquanto a regressão ridge ainda pode ter um bom desempenho, trocando um pequeno aumento no viés por uma grande diminuição na variância. Portanto, a regressão ridge funciona melhor em situações onde as estimativas de mínimos quadrados têm alta variância.

A regressão ridge também tem vantagens computacionais substanciais sobre a seleção do melhor subconjunto, que exige a busca através de \(2^p\) modelos. Como discutimos anteriormente, mesmo para valores moderados de \(p\), essa busca pode ser inviável computacionalmente. Em contraste, para qualquer valor fixo de \(\lambda\), a regressão ridge ajusta apenas um modelo, e o procedimento de ajuste do modelo pode ser realizado muito rapidamente. De fato, pode-se mostrar que os cálculos necessários para resolver (6.5), simultaneamente para todos os valores de \(\lambda\), são quase idênticos aos necessários para ajustar um modelo usando mínimos quadrados.

6.2.2 - O Lasso

A regressão ridge tem uma desvantagem óbvia. Ao contrário da seleção do melhor subconjunto, stepwise progressiva e stepwise regressiva, que geralmente selecionam modelos que envolvem apenas um subconjunto das variáveis, a regressão ridge incluirá todos os \(p\) preditores no modelo final. A penalidade \(\lambda \sum_{j=1}^{p} \beta_j^2\) na Equação 6.5 reduzirá todos os coeficientes em direção a zero, mas não definirá nenhum deles exatamente como zero (a menos que \(\lambda = \infty\)). Isso pode não ser um problema para a precisão da previsão, mas pode criar um desafio na interpretação do modelo em contextos nos quais o número de variáveis \(p\) é bastante grande. Por exemplo, no conjunto de dados Credit, parece que as variáveis mais importantes são income, limit, rating e student. Portanto, podemos desejar construir um modelo incluindo apenas esses preditores. No entanto, a regressão ridge sempre gerará um modelo envolvendo todos os dez preditores. Aumentar o valor de \(\lambda\) tende a reduzir as magnitudes dos coeficientes, mas não resultará na exclusão de nenhuma das variáveis.

O lasso é uma alternativa relativamente recente à regressão ridge que supera essa desvantagem. Os coeficientes do lasso, \(\hat{\beta}^L_{\lambda}\), minimizam a quantidade \[ \sum_{i=1}^{n} \left( y_i - \beta_0 - \sum_{j=1}^{p} \beta_j x_{ij} \right)^2 + \lambda \sum_{j=1}^{p} |\beta_j| = RSS + \lambda \sum_{j=1}^{p} |\beta_j|. \]

Comparando (6.7) com (6.5), vemos que o lasso e a regressão ridge têm formulações semelhantes. A única diferença é que o termo \(\beta_j^2\) na penalidade da regressão ridge (6.5) foi substituído por \(|\beta_j|\) na penalidade do lasso (6.7). No jargão estatístico, o lasso usa uma penalidade \(\ell_1\) em vez de uma penalidade \(\ell_2\). A norma \(\ell_1\) de um vetor de coeficientes \(\beta\) é dada por \(\|\beta\|_1 = \sum |\beta_j|\).

Assim como na regressão ridge, o lasso reduz as estimativas dos coeficientes em direção a zero. No entanto, no caso do lasso, a penalidade \(\ell_1\) tem o efeito de forçar algumas das estimativas dos coeficientes a serem exatamente iguais a zero quando o parâmetro de ajuste \(\lambda\) é suficientemente grande. Assim, muito parecido com a seleção do melhor subconjunto, o lasso realiza a seleção de variáveis. Como resultado, os modelos gerados pelo lasso são geralmente muito mais fáceis de interpretar do que aqueles produzidos pela regressão ridge. Dizemos que o lasso produz modelos esparsos—isto é, modelos que envolvem apenas um subconjunto das variáveis. Assim como na regressão ridge, selecionar um bom valor de \(\lambda\) para o lasso é crucial; adiamos essa discussão para a Seção 6.2.3, onde usamos a validação cruzada.

Como exemplo, considere os gráficos de coeficientes na Figura 6.6, que são gerados aplicando o lasso ao conjunto de dados Credit. Quando \(\lambda = 0\), o lasso simplesmente fornece o ajuste dos mínimos quadrados, e quando \(\lambda\) se torna suficientemente grande, o lasso fornece o modelo nulo no qual todas as estimativas dos coeficientes são zero. No entanto, entre esses dois extremos, os modelos de regressão ridge e lasso são bastante diferentes entre si. Movendo-se da esquerda para a direita no painel direito da Figura 6.6, observamos que, a princípio, o lasso resulta em um modelo que contém apenas o preditor rating. Em seguida, student e limit entram no modelo quase simultaneamente, seguidos por income. Eventualmente, as variáveis restantes entram no modelo. Portanto, dependendo do valor de \(\lambda\), o lasso pode produzir um modelo envolvendo qualquer número de variáveis. Em contraste, a regressão ridge sempre incluirá todas as variáveis no modelo, embora a magnitude das estimativas dos coeficientes dependa de \(\lambda\).

Outra Formulação para Regressão Ridge e Lasso

Pode-se mostrar que as estimativas dos coeficientes da regressão lasso e ridge resolvem os problemas \[ \text{minimizar}_{\beta} \left\{ \sum_{i=1}^{n} \left( y_i - \beta_0 - \sum_{j=1}^{p} \beta_j x_{ij} \right)^2 \right\} \quad \text{sujeito a} \quad \sum_{j=1}^{p} |\beta_j| \leq s \] e \[ \text{minimizar}_{\beta} \left\{ \sum_{i=1}^{n} \left( y_i - \beta_0 - \sum_{j=1}^{p} \beta_j x_{ij} \right)^2 \right\} \quad \text{ sujeito a} \quad \sum_{j=1}^{p} \beta_j^2 \leq s, \] respectivamente. Em outras palavras, para cada valor de \(\lambda\), existe algum \(s\) tal que as Equações (6.7) e (6.8) darão as mesmas estimativas dos coeficientes do lasso. Da mesma forma, para cada valor de \(\lambda\) existe um \(s\) correspondente tal que as Equações (6.5) e (6.9) darão as mesmas estimativas dos coeficientes da regressão ridge. Quando \(p = 2\), então (6.8) indica que as estimativas dos coeficientes do lasso têm o menor RSS de todos os pontos que estão dentro do diamante definido por \(|\beta_1| + |\beta_2| \leq s\). Da mesma forma, as estimativas da regressão ridge têm o menor RSS de todos os pontos que estão dentro do círculo definido por $_1^2 + \(\beta_2^2 \leq s\).

Podemos pensar na Equação (6.8) da seguinte forma. Quando realizamos o lasso, estamos tentando encontrar o conjunto de estimativas de coeficientes que levam ao menor RSS, sujeito à restrição de que existe um limite \(s\) para o quão grande \(\sum_{j=1}^{p} |\beta_j|\) pode ser. Quando \(s\) é extremamente grande, esse limite não é muito restritivo, e assim as estimativas dos coeficientes podem ser grandes. De fato, se \(s\) é grande o suficiente para que a solução dos mínimos quadrados esteja dentro do limite, então (6.8) simplesmente fornecerá a solução dos mínimos quadrados. Em contraste, se \(s\) é pequeno, então \(\sum_{j=1}^{p} |\beta_j|\) deve ser pequeno para evitar violar o limite. Da mesma forma, (6.9) indica que, quando realizamos a regressão ridge, buscamos um conjunto de estimativas de coeficientes tal que o RSS seja o menor possível, sujeito ao requisito de que \(\sum_{j=1}^{p} \beta_j^2\) não exceda o limite \(s\).

As formulações (6.8) e (6.9) revelam uma conexão estreita entre o lasso, a regressão ridge e a seleção do melhor subconjunto. Considere o problema \[ \text{minimizar}_{\beta} \left\{ \sum_{i=1}^{n} \left( y_i - \beta_0 - \sum_{j=1}^{p} \beta_j x_{ij} \right)^2 \right\} \quad \text{sujeito a} \quad \sum_{j=1}^{p} I(\beta_j \neq 0) \leq s. \]

Aqui, \(I(\beta_j \neq 0)\) é uma variável indicadora: assume o valor 1 se \(\beta_j \neq 0\) e igual a zero caso contrário. Então, (6.10) equivale a encontrar um conjunto de estimativas de coeficientes tal que o RSS seja o menor possível, sujeito à restrição de que no máximo \(s\) coeficientes podem ser diferentes de zero. O problema (6.10) é equivalente à seleção do melhor subconjunto. Infelizmente, resolver (6.10) é inviável computacionalmente quando \(p\) é grande, pois exige considerar todos os modelos contendo \(s\) preditores. Portanto, podemos interpretar a regressão ridge e o lasso como alternativas computacionalmente viáveis à seleção do melhor subconjunto, que substituem a forma intratável do limite em (6.10) por formas que são muito mais fáceis de resolver. Claro, o lasso está muito mais relacionado à seleção do melhor subconjunto, pois o lasso realiza a seleção de variáveis para \(s\) suficientemente pequeno em (6.8), enquanto a regressão ridge não.

A Propriedade de Seleção de Variáveis do Lasso

Por que o lasso, ao contrário da regressão ridge, resulta em estimativas de coeficientes que são exatamente iguais a zero? As formulações (6.8) e (6.9) podem ser usadas para esclarecer a questão. A Figura 6.7 ilustra a situação. A solução dos mínimos quadrados é marcada como \(\hat{\beta}\), enquanto o diamante azul e o círculo representam as restrições do lasso e da regressão ridge em (6.8) e (6.9), respectivamente. Se \(s\) for suficientemente grande, então as regiões de restrição conterão \(\hat{\beta}\), e assim as estimativas da regressão ridge e do lasso serão as mesmas que as estimativas dos mínimos quadrados. (Um valor tão grande de \(s\) corresponde a \(\lambda = 0\) em (6.5) e (6.7).) No entanto, na Figura 6.7, as estimativas dos mínimos quadrados estão fora do diamante e do círculo, e assim as estimativas dos mínimos quadrados não são as mesmas que as estimativas da regressão ridge e do lasso.

Cada uma das elipses centradas em \(\hat{\beta}\) representa um contorno: isso significa que todos os pontos em uma elipse particular têm o mesmo valor de RSS. À medida que as elipses se expandem para longe das estimativas dos coeficientes de mínimos quadrados, o RSS aumenta. As Equações (6.8) e (6.9) indicam que as estimativas dos coeficientes da regressão ridge e do lasso são dadas pelo primeiro ponto em que uma elipse contata a região de restrição. Como a regressão ridge tem uma restrição circular sem pontos afiados, essa interseção geralmente não ocorrerá em um eixo, e assim as estimativas dos coeficientes da regressão ridge serão exclusivamente não nulas. No entanto, a restrição do lasso tem cantos em cada um dos eixos, e assim a elipse frequentemente intersectará a região de restrição em um eixo. Quando isso ocorre, um dos coeficientes será igual a zero. Em dimensões mais altas, muitas das estimativas dos coeficientes podem ser iguais a zero simultaneamente. Na Figura 6.7, a interseção ocorre em \(\beta_1 = 0\), e assim o modelo resultante incluirá apenas \(\beta_2\).

Na Figura 6.7, consideramos o caso simples de \(p = 2\). Quando \(p = 3\), a região de restrição para a regressão ridge se torna uma esfera, e a região de restrição para o lasso se torna um poliedro. Quando \(p > 3\), a restrição para a regressão ridge se torna uma hiperesfera, e a restrição para o lasso se torna um politopo. No entanto, as ideias principais mostradas na Figura 6.7 ainda se aplicam. Em particular, o lasso leva à seleção de características quando \(p > 2\) devido aos cantos afiados do poliedro ou politopo.

Comparando Lasso e Regressão Ridge

É claro que o lasso tem uma grande vantagem sobre a regressão ridge, na medida em que produz modelos mais simples e interpretáveis que envolvem apenas um subconjunto dos preditores. No entanto, qual método leva a uma melhor precisão de previsão? A Figura 6.8 exibe a variância, o viés quadrado e o MSE de teste do lasso aplicado aos mesmos dados simulados da Figura 6.5. Claramente, o lasso leva a um comportamento qualitativamente semelhante à regressão ridge, na medida em que, à medida que \(\lambda\) aumenta, a variância diminui e o viés aumenta. No painel direito da Figura 6.8, as linhas pontilhadas representam os ajustes da regressão ridge. Aqui, plotamos ambos contra seus \(R^2\) nos dados de treinamento. Esta é outra forma útil de indexar modelos e pode ser usada para comparar modelos com diferentes tipos de regularização, como é o caso aqui. Neste exemplo, o lasso e a regressão ridge resultam em vieses quase idênticos. No entanto, a variância da regressão ridge é ligeiramente menor do que a variância do lasso. Consequentemente, o MSE mínimo da regressão ridge é ligeiramente menor do que o do lasso.

No entanto, os dados na Figura 6.8 foram gerados de tal forma que todos os 45 preditores estavam relacionados à resposta—isto é, nenhum dos coeficientes verdadeiros \(\beta_1, ..., \beta_{45}\) era igual a zero. O lasso implicitamente assume que vários coeficientes são realmente iguais a zero. Consequentemente, não é surpreendente que a regressão ridge supere o lasso em termos de erro de previsão nesse cenário. A Figura 6.9 ilustra uma situação semelhante, exceto que agora a resposta é uma função de apenas 2 dos 45 preditores. Agora, o lasso tende a superar a regressão ridge em termos de viés, variância e MSE.

Esses dois exemplos ilustram que nem a regressão ridge nem o lasso dominarão universalmente o outro. Em geral, pode-se esperar que o lasso tenha um desempenho melhor em um cenário onde um número relativamente pequeno de preditores tenha coeficientes substanciais, e os preditores restantes tenham coeficientes muito pequenos ou iguais a zero. A regressão ridge terá um desempenho melhor quando a resposta for uma função de muitos preditores, todos com coeficientes de tamanho aproximadamente igual. No entanto, o número de preditores relacionados à resposta nunca é conhecido a priori para conjuntos de dados reais. Uma técnica como a validação cruzada pode ser usada para determinar qual abordagem é melhor em um conjunto de dados específico.

Assim como na regressão ridge, quando as estimativas de mínimos quadrados têm variância excessivamente alta, a solução do lasso pode resultar em uma redução da variância ao custo de um pequeno aumento no viés, e, consequentemente, pode gerar previsões mais precisas. Ao contrário da regressão ridge, o lasso realiza a seleção de variáveis e, portanto, resulta em modelos mais fáceis de interpretar.

Existem algoritmos muito eficientes para ajustar modelos de regressão ridge e lasso; em ambos os casos, todos os caminhos dos coeficientes podem ser computados com aproximadamente a mesma quantidade de trabalho que um único ajuste de mínimos quadrados. Exploraremos isso mais adiante no laboratório no final deste capítulo.

Um Caso Especial Simples para Regressão Ridge e Lasso

Para obter uma melhor intuição sobre o comportamento da regressão ridge e do lasso, considere um caso especial simples com \(n = p\) e \(X\) uma matriz diagonal com 1’s na diagonal e 0’s em todos os elementos fora da diagonal. Para simplificar ainda mais o problema, suponha também que estamos realizando regressão sem intercepto. Com essas suposições, o problema usual dos mínimos quadrados se simplifica para encontrar \(\beta_1, ..., \beta_p\) que minimizem \[ \sum_{j=1}^{p} (y_j - \beta_j)^2. \] Nesse caso, a solução dos mínimos quadrados é dada por \[ \hat{\beta}_j = y_j. \] E, nesse cenário, a regressão ridge consiste em encontrar \(\beta_1, ..., \beta_p\) de forma que \[ \sum_{j=1}^{p} (y_j - \beta_j)^2 + \lambda \sum_{j=1}^{p} \beta_j^2 \] seja minimizado, e o lasso consiste em encontrar os coeficientes de forma que \[ \sum_{j=1}^{p} (y_j - \beta_j)^2 + \lambda \sum_{j=1}^{p} |\beta_j| \] seja minimizado. Pode-se mostrar que, nesse cenário, as estimativas da regressão ridge assumem a forma \[ \hat{\beta}_j^R = \frac{y_j}{1 + \lambda}, \] e as estimativas do lasso assumem a forma \[ \hat{\beta}_j^L = \begin{cases} y_j - \lambda/2 & \text{se } y_j > \lambda/2; \\ y_j + \lambda/2 & \text{se } y_j < -\lambda/2; \\ 0 & \text{se } |y_j| \leq \lambda/2. \end{cases} \]

A Figura 6.10 exibe a situação. Podemos ver que a regressão ridge e o lasso realizam dois tipos muito diferentes de redução. Na regressão ridge, cada estimativa dos coeficientes dos mínimos quadrados é reduzida pela mesma proporção. Em contraste, o lasso reduz cada coeficiente dos mínimos quadrados em direção a zero por uma quantidade constante, \(\lambda/2\); os coeficientes dos mínimos quadrados que são menores que \(\lambda/2\) em valor absoluto são reduzidos inteiramente a zero. O tipo de redução realizado pelo lasso neste cenário simples (6.15) é conhecido como limiarização suave. O fato de que alguns coeficientes do lasso são reduzidos inteiramente a zero explica por que o lasso realiza seleção de características.

No caso de uma matriz de dados \(X\) mais geral, a situação é um pouco mais complicada do que o que é mostrado na Figura 6.10, mas as ideias principais ainda se mantêm aproximadamente: a regressão ridge mais ou menos reduz cada dimensão dos dados pela mesma proporção, enquanto o lasso mais ou menos reduz todos os coeficientes em direção a zero por uma quantidade semelhante, e coeficientes suficientemente pequenos são reduzidos completamente a zero.

Interpretação Bayesiana da Regressão Ridge e do Lasso

Mostramos agora que podemos ver a regressão ridge e o lasso através de uma lente bayesiana. Um ponto de vista bayesiano para a regressão assume que o vetor de coeficientes \(\beta\) tem alguma distribuição a priori, digamos \(p(\beta)\), onde \(\beta = (\beta_0, \beta_1, ..., \beta_p)^T\). A verossimilhança dos dados pode ser escrita como \(f(Y |X, \beta)\), onde \(X = (X_1, ..., X_p)\). Multiplicar a distribuição a priori pela verossimilhança nos dá (até uma constante de proporcionalidade) a distribuição a posteriori, que assume a forma \[ p(\beta|X, Y ) \propto f(Y |X, \beta)p(\beta|X) = f(Y |X, \beta)p(\beta), \] onde a proporcionalidade acima segue do teorema de Bayes, e a igualdade acima segue da suposição de que \(X\) é fixo.

Assumimos o modelo linear usual, \[ Y = \beta_0 + X_1\beta_1 + \cdots + X_p\beta_p + \epsilon, \] e supomos que os erros são independentes e provenientes de uma distribuição normal. Além disso, assumimos que \(p(\beta) = \prod_{j=1}^{p} g(\beta_j)\), para alguma função densidade \(g\). Acontece que a regressão ridge e o lasso seguem naturalmente de dois casos especiais de \(g\): - Se \(g\) é uma distribuição Gaussiana com média zero e desvio padrão uma função de \(\lambda\), então segue que o modo a posteriori para \(\beta\)—isto é, o valor mais provável para \(\beta\), dados os dados—é dado pela solução da regressão ridge. (De fato, a solução da regressão ridge é também a média a posteriori.) - Se \(g\) é uma distribuição exponencial dupla (Laplace) com média zero e parâmetro de escala uma função de \(\lambda\), então segue que o modo a posteriori para \(\beta\) é a solução do lasso. (No entanto, a solução do lasso não é a média a posteriori e, na verdade, a média a posteriori não produz um vetor de coeficientes esparsos.)

As distribuições a priori Gaussiana e exponencial dupla são exibidas na Figura 6.11. Portanto, do ponto de vista bayesiano, a regressão ridge e o lasso seguem diretamente de assumir o modelo linear usual com erros normais, juntamente com uma simples distribuição a priori para \(\beta\). Note que a distribuição a priori do lasso é fortemente inclinada em zero, enquanto a Gaussiana é mais plana em zero. Assim, o lasso espera a priori que muitos dos coeficientes sejam (exatamente) zero, enquanto a regressão ridge assume que os coeficientes estão distribuídos aleatoriamente em torno de zero.

6.2.3 - Selecionando o Parâmetro de Ajuste

Assim como as abordagens de seleção de subconjuntos consideradas na Seção 6.1 requerem um método para determinar qual dos modelos em consideração é o melhor, implementar a regressão ridge e o lasso requer um método para selecionar um valor para o parâmetro de ajuste \(\lambda\) em (6.5) e (6.7), ou, de forma equivalente, o valor da restrição \(s\) em (6.9) e (6.8). A validação cruzada fornece uma maneira simples de resolver esse problema. Escolhemos uma grade de valores de \(\lambda\) e calculamos o erro de validação cruzada para cada valor de \(\lambda\), conforme descrito no Capítulo 5. Em seguida, selecionamos o valor do parâmetro de ajuste para o qual o erro de validação cruzada é o menor. Finalmente, o modelo é ajustado novamente usando todas as observações disponíveis e o valor selecionado do parâmetro de ajuste.

6.3 - Métodos de Redução de Dimensão

Os métodos que discutimos até agora neste capítulo controlaram a variância de duas maneiras diferentes: usando um subconjunto das variáveis originais ou reduzindo seus coeficientes em direção a zero. Todos esses métodos são definidos usando os preditores originais, \(X_1, X_2, ..., X_p\). Agora exploramos uma classe de abordagens que transformam os preditores e, em seguida, ajustam um modelo de mínimos quadrados usando as variáveis transformadas. Chamaremos essas técnicas de métodos de redução de dimensão.

Deixe \(Z_1, Z_2, ..., Z_M\) representar \(M < p\) combinações lineares de nossos \(p\) preditores originais. Ou seja, \[ Z_m = \sum_{j=1}^{p} \phi_{jm} X_j, \] para algumas constantes \(\phi_{1m}, \phi_{2m}, ..., \phi_{pm}, m = 1, ..., M\). Podemos então ajustar o modelo de regressão linear \[ y_i = \theta_0 + \sum_{m=1}^{M} \theta_m z_{im} + \epsilon_i, \quad i = 1, ..., n, \]

usando mínimos quadrados. Note que em (6.17), os coeficientes de regressão são dados por \(\theta_0, \theta_1, ..., \theta_M\). Se as constantes \(\phi_{1m}, \phi_{2m}, ..., \phi_{pm}\) forem escolhidas sabiamente, essas abordagens de redução de dimensão podem frequentemente superar a regressão linear por mínimos quadrados. Em outras palavras, ajustar (6.17) usando mínimos quadrados pode levar a melhores resultados do que ajustar (6.1) usando mínimos quadrados.

O termo redução de dimensão vem do fato de que essa abordagem reduz o problema de estimar os \(p + 1\) coeficientes \(\beta_0, \beta_1, ..., \beta_p\) para o problema mais simples de estimar os \(M + 1\) coeficientes \(\theta_0, \theta_1, ..., \theta_M\), onde \(M < p\). Em outras palavras, a dimensão do problema foi reduzida de \(p + 1\) para \(M + 1\).

Note que a partir de (6.16), \[ \sum_{m=1}^{M} \theta_m z_{im} = \sum_{m=1}^{M} \theta_m \sum_{j=1}^{p} \phi_{jm} x_{ij} = \sum_{j=1}^{p} \sum_{m=1}^{M} \theta_m \phi_{jm} x_{ij} = \sum_{j=1}^{p} \beta_j x_{ij}, \] onde \[ \beta_j = \sum_{m=1}^{M} \theta_m \phi_{jm}. \]

Portanto, (6.17) pode ser pensado como um caso especial do modelo de regressão linear original dado por (6.1). A redução de dimensão serve para restringir as estimativas dos coeficientes \(\beta_j\), já que agora eles devem assumir a forma (6.18). Essa restrição na forma dos coeficientes tem o potencial de enviesar as estimativas dos coeficientes. No entanto, em situações onde \(p\) é grande em relação a \(n\), selecionar um valor de \(M\) pequeno pode reduzir significativamente a variância dos coeficientes ajustados. Se \(M = p\) e todos os \(Z_m\) são linearmente independentes, então (6.18) não impõe restrições. Nesse caso, não ocorre redução de dimensão e, portanto, ajustar (6.17) é equivalente a realizar mínimos quadrados nos \(p\) preditores originais.

Todos os métodos de redução de dimensão funcionam em duas etapas. Primeiro, os preditores transformados \(Z_1, Z_2, ..., Z_M\) são obtidos. Segundo, o modelo é ajustado usando esses \(M\) preditores. No entanto, a escolha de \(Z_1, Z_2, ..., Z_M\), ou de forma equivalente, a seleção dos \(\phi_{jm}\), pode ser alcançada de diferentes maneiras. Neste capítulo, consideraremos duas abordagens para essa tarefa: componentes principais e mínimos quadrados parciais.

6.3.1 - Regressão de Componentes Principais

A análise de componentes principais (PCA) é uma abordagem popular para derivar um conjunto de características de baixa dimensão a partir de um grande conjunto de variáveis. A PCA é discutida em mais detalhes como uma ferramenta para aprendizado não supervisionado no Capítulo 12. Aqui, descrevemos seu uso como uma técnica de redução de dimensão para regressão.

Visão Geral da Análise de Componentes Principais

A PCA é uma técnica para reduzir a dimensão de uma matriz de dados \(n \times p\) \(X\). A primeira direção do componente principal dos dados é aquela ao longo da qual as observações variam mais. Por exemplo, considere a Figura 6.14, que mostra o tamanho da população (pop) em dezenas de milhares de pessoas e os gastos com publicidade (ad) para uma determinada

empresa em milhares de dólares, para 100 cidades. A linha verde sólida representa a primeira direção do componente principal dos dados. Podemos ver a olho nu que esta é a direção ao longo da qual há a maior variabilidade nos dados. Ou seja, se projetássemos as 100 observações nesta linha (como mostrado no painel esquerdo da Figura 6.15), então as observações projetadas resultantes teriam a maior variância possível; projetar as observações em qualquer outra linha resultaria em observações projetadas com menor variância. Projetar um ponto em uma linha simplesmente envolve encontrar a localização na linha que está mais próxima do ponto.

O primeiro componente principal é exibido graficamente na Figura 6.14, mas como ele pode ser resumido matematicamente? Ele é dado pela fórmula \[ Z_1 = 0.839 \times (\text{pop} - \overline{\text{pop}}) + 0.544 \times (\text{ad} - \overline{\text{ad}}). \]

Aqui, \(\phi_{11} = 0.839\) e \(\phi_{21} = 0.544\) são as cargas do componente principal, que definem a direção referida acima. Em (6.19), pop indica a média de todos os valores de pop neste conjunto de dados, e ad indica a média de todos os gastos com publicidade. A ideia é que, de todas as possíveis combinações lineares de pop e ad tais que \(\phi_{11}^2 + \phi_{21}^2 = 1\), essa combinação linear específica produz a maior variância: ou seja, essa é a combinação linear para a qual \(\text{Var}(\phi_{11} \times (\text{pop} - \overline{\text{pop}}) + \phi_{21} \times (\text{ad} - \overline{\text{ad}}))\) é maximizada. É necessário considerar apenas combinações lineares da forma \(\phi_{11}^2 + \phi_{21}^2 = 1\), pois, caso contrário, poderíamos aumentar \(\phi_{11}\) e \(\phi_{21}\) arbitrariamente para aumentar a variância. Em (6.19), as duas cargas são ambas positivas e têm tamanhos semelhantes, então \(Z_1\) é quase uma média das duas variáveis.

Como \(n = 100\), pop e ad são vetores de comprimento 100, e assim é \(Z_1\) em (6.19). Por exemplo, \[ z_{i1} = 0.839 \times (\text{pop}_i - \overline{\text{pop}}) + 0.544 \times (\text{ad}_i - \overline{\text{ad}}). \]

Os valores de \(z_{11}, ..., z_{n1}\) são conhecidos como escores dos componentes principais, e podem ser vistos no painel direito da Figura 6.15.

Há também outra interpretação da PCA: o vetor do primeiro componente principal define a linha que está o mais próximo possível dos dados. Por exemplo, na Figura 6.14, a linha do primeiro componente principal minimiza a soma das distâncias perpendiculares ao quadrado entre cada ponto e a linha. Essas distâncias são plotadas como segmentos de linha tracejados no painel esquerdo da Figura 6.15, em que as cruzes representam a projeção de cada ponto na linha do primeiro componente principal. O primeiro componente principal foi escolhido de modo que as observações projetadas estejam o mais próximo possível das observações originais.

No painel direito da Figura 6.15, o painel esquerdo foi rotacionado para que a direção do primeiro componente principal coincida com o eixo x. É possível mostrar que o escore do primeiro componente principal para a \(i\)-ésima observação, dado em (6.20), é a distância na direção x da \(i\)-ésima cruz a partir de zero. Então, por exemplo, o ponto no canto inferior esquerdo do painel esquerdo da Figura 6.15 tem um escore do componente principal grande e negativo, \(z_{i1} = -26.1\), enquanto o ponto no canto superior direito tem um escore grande e positivo, \(z_{i1} = 18.7\). Esses escores podem ser computados diretamente usando (6.20).

Podemos pensar nos valores do componente principal \(Z_1\) como resumos de um único número dos orçamentos conjuntos de pop e ad para cada local. Neste exemplo, se \(z_{i1} = 0.839 \times (\text{pop}_i - \overline{\text{pop}}) + 0.544 \times (\text{ad}_i - \overline{\text{ad}}) < 0\), isso indica uma cidade com tamanho de população abaixo da média e gastos com publicidade abaixo da média. Um escore positivo sugere o contrário. Quão bem um único número pode representar tanto pop quanto ad? Neste caso, a Figura 6.14 indica que pop e ad têm aproximadamente uma relação linear, então podemos esperar que um resumo de um único número funcione bem. A Figura 6.16 exibe \(z_{i1}\) versus tanto pop quanto ad. Os gráficos mostram uma forte relação entre o primeiro componente principal e as duas características. Em outras palavras, o primeiro componente principal parece capturar a maior parte das informações contidas nos preditores pop e ad.

Até agora, concentramos-nos no primeiro componente principal. Em geral, pode-se construir até \(p\) componentes principais distintos. O segundo componente principal \(Z_2\) é uma combinação linear das variáveis que é não correlacionada com \(Z_1\), e tem a maior variância sujeita a essa restrição. A direção do segundo componente principal é ilustrada como uma linha azul tracejada na Figura 6.14. Acontece que a condição de correlação zero de \(Z_1\) com \(Z_2\) é equivalente à condição de que a direção deve ser perpendicular, ou ortogonal, à direção do primeiro componente principal. O segundo componente principal é dado pela fórmula \[ Z_2 = 0.544 \times (\text{pop} - \overline{\text{pop}}) - 0.839 \times (\text{ad} - \overline{\text{ad}}). \]

Como os dados de publicidade têm dois preditores, os dois primeiros componentes principais contêm todas as informações que estão em pop e ad. No entanto, por construção, o primeiro componente conterá a maior parte das informações. Considere, por exemplo, a variabilidade muito maior de \(z_{i1}\) (o eixo x) versus \(z_{i2}\) (o eixo y) no painel direito da Figura 6.15. O fato de que os escores do segundo componente principal estão muito mais próximos de zero indica que este componente captura muito menos informações. Como outra ilustração, a Figura 6.17 exibe \(z_{i2}\) versus pop e ad. Há pouca relação entre o segundo componente principal e esses dois preditores, novamente sugerindo que, neste caso, apenas o primeiro componente principal é necessário para representar com precisão os orçamentos de pop e ad.

Com dados bidimensionais, como em nosso exemplo de publicidade, podemos construir no máximo dois componentes principais. No entanto, se tivéssemos outros preditores, como idade da população, nível de renda, educação, e assim por diante, então componentes adicionais poderiam ser construídos. Eles sucessivamente maximizariam a variância, sujeito à restrição de serem não correlacionados com os componentes anteriores.

Abordagem de Regressão por Componentes Principais

A abordagem de regressão por componentes principais (PCR) envolve a construção dos primeiros \(M\) componentes principais, \(Z_1, ..., Z_M\), e então usar esses componentes como preditores em um modelo de regressão linear que é ajustado usando mínimos quadrados. A ideia principal é que muitas vezes um pequeno número de componentes principais é suficiente para explicar a maior parte da variabilidade nos dados, bem como a relação com a resposta. Em outras palavras, assumimos que as direções em que \(X_1, ..., X_p\) mostram a maior variação são as direções associadas a \(Y\). Embora essa suposição não seja garantida, muitas vezes acaba sendo uma aproximação razoavelmente boa para dar bons resultados.

Se a suposição subjacente ao PCR for válida, então ajustar um modelo de mínimos quadrados a \(Z_1, ..., Z_M\) levará a melhores resultados do que ajustar um modelo de mínimos quadrados a \(X_1, ..., X_p\), uma vez que a maior parte ou todas as informações nos dados que se relacionam com a resposta estão contidas em \(Z_1, ..., Z_M\), e ao estimar apenas \(M \ll p\) coeficientes, podemos mitigar o sobreajuste. Nos dados de publicidade, o primeiro componente principal explica a maior parte da variância em pop e ad, então uma regressão por componentes principais que usa essa única variável para prever alguma resposta de interesse, como vendas, provavelmente terá um bom desempenho.

A Figura 6.18 exibe os ajustes de PCR nos conjuntos de dados simulados das Figuras 6.8 e 6.9. Lembre-se de que ambos os conjuntos de dados foram gerados usando \(n = 50\) observações e \(p = 45\) preditores. No entanto, enquanto a resposta no primeiro conjunto de dados era uma função de todos os preditores, a resposta no segundo conjunto de dados foi gerada usando apenas dois dos preditores. As curvas são plotadas como uma função de \(M\), o número de componentes principais usados como preditores no modelo de regressão. À medida que mais componentes principais são usados no modelo de regressão, o viés diminui, mas a variância aumenta. Isso resulta em uma forma típica de U para o erro quadrático médio. Quando \(M = p = 45\), então o PCR equivale simplesmente a um ajuste de mínimos quadrados usando todos os preditores originais. A figura indica que realizar PCR com uma escolha apropriada de \(M\) pode resultar em uma melhoria substancial em relação aos mínimos quadrados, especialmente no painel esquerdo. No entanto, ao examinar os resultados da regressão ridge e do lasso nas Figuras 6.5, 6.8 e 6.9, vemos que o PCR não se sai tão bem quanto os dois métodos de redução neste exemplo.

O desempenho relativamente pior do PCR na Figura 6.18 é consequência do fato de que os dados foram gerados de tal forma que muitos componentes principais são necessários para modelar adequadamente a resposta. Em contraste, o PCR tende a se sair bem em casos quando os primeiros poucos componentes principais são suficientes para capturar a maior parte da variação nos preditores, bem como a relação com a resposta. O painel esquerdo da Figura 6.19 ilustra os resultados de outro conjunto de dados simulado projetado para ser mais favorável ao PCR. Aqui a resposta foi gerada de tal forma que depende exclusivamente dos primeiros cinco componentes principais. Agora o viés cai rapidamente para zero à medida que \(M\), o número de componentes principais usados no PCR, aumenta. O erro quadrático médio exibe um mínimo claro em \(M = 5\). O painel direito da Figura 6.19 exibe os resultados nesses dados usando regressão ridge e o lasso. Todos os três métodos oferecem uma melhoria significativa em relação aos mínimos quadrados. No entanto, o PCR e a regressão ridge superam ligeiramente o lasso.

Notamos que, embora o PCR forneça uma maneira simples de realizar regressão usando \(M \ll p\) preditores, ele não é um método de seleção de características. Isso ocorre porque cada um dos \(M\) componentes principais usados na regressão é uma combinação linear de todos os \(p\) recursos originais. Por exemplo, em (6.19), \(Z_1\) era uma combinação linear de pop e ad. Portanto, embora o PCR frequentemente tenha um bom desempenho em muitos cenários práticos, ele não resulta no desenvolvimento de um modelo que dependa de um pequeno conjunto de características originais. Nesse sentido, o PCR está mais relacionado à regressão ridge do que ao lasso. Na verdade, pode-se mostrar que o PCR e a regressão ridge são muito intimamente relacionados. Pode-se até pensar na regressão ridge como uma versão contínua do PCR!

No PCR, o número de componentes principais, \(M\), é tipicamente escolhido por validação cruzada. Os resultados da aplicação do PCR ao conjunto de dados Credit são mostrados na Figura 6.20; o painel direito exibe os erros de validação cruzada obtidos, em função de \(M\). Nesses dados, o menor erro de validação cruzada ocorre quando há \(M = 10\) componentes; isso corresponde a quase nenhuma redução de dimensão, já que o PCR com \(M = 11\) é equivalente a simplesmente realizar mínimos quadrados.

Ao realizar PCR, geralmente recomendamos padronizar cada preditor, usando (6.6), antes de gerar os componentes principais. Essa padronização garante que todas as variáveis estejam na mesma escala. Na ausência de padronização, as variáveis de alta variância tenderão a desempenhar um papel maior nos componentes principais obtidos, e a escala em que as variáveis são medidas terá, em última análise, um efeito no modelo final do PCR. No entanto, se as variáveis são todas medidas nas mesmas unidades (por exemplo, quilogramas ou polegadas), pode-se optar por não padronizá-las.

6.3.2 - Mínimos Quadrados Parciais

A abordagem PCR que acabamos de descrever envolve identificar combinações lineares, ou direções, que melhor representam os preditores \(X_1, ..., X_p\). Essas direções são identificadas de maneira não supervisionada, pois a resposta \(Y\) não é usada para ajudar a determinar as direções dos componentes principais. Ou seja, a resposta não supervisiona a identificação dos componentes principais. Consequentemente, o PCR sofre de uma desvantagem: não há garantia de que as direções que melhor explicam os preditores também serão as melhores direções para prever a resposta. Métodos não supervisionados são discutidos mais detalhadamente no Capítulo 12.

Agora apresentamos os mínimos quadrados parciais (PLS), uma alternativa supervisionada ao PCR. Assim como o PCR, o PLS é um método de redução de dimensão, que primeiro identifica um novo conjunto de características \(Z_1, ..., Z_M\) que são combinações lineares das características originais, e depois ajusta um modelo linear por mínimos quadrados usando essas \(M\) novas características. Mas, ao contrário do PCR, o PLS identifica essas novas características de maneira supervisionada — isto é, faz uso da resposta \(Y\) para identificar novas características que não apenas aproximam bem as características antigas, mas também estão relacionadas à resposta. Grosso modo, a abordagem PLS tenta encontrar direções que ajudem a explicar tanto a resposta quanto os preditores.

Agora descrevemos como a primeira direção do PLS é computada. Após padronizar os \(p\) preditores, o PLS calcula a primeira direção \(Z_1\) definindo cada \(\phi_{j1}\) em (6.16) igual ao coeficiente da regressão linear simples de \(Y\) em \(X_j\). Pode-se mostrar que esse coeficiente é proporcional à correlação entre \(Y\) e \(X_j\). Portanto, ao calcular \(Z_1 = \sum_{j=1}^{p} \phi_{j1} X_j\), o PLS atribui o maior peso às variáveis que estão mais fortemente relacionadas à resposta.

A Figura 6.21 exibe um exemplo de PLS em um conjunto de dados sintético com Vendas em cada uma das 100 regiões como resposta, e dois preditores: Tamanho da População e Gastos com Publicidade. A linha verde sólida indica a primeira direção do PLS, enquanto a linha pontilhada mostra a primeira direção do componente principal. O PLS escolheu uma direção que tem menos variação na dimensão de publicidade por unidade de variação na dimensão de população, em relação ao PCA. Isso sugere que a população está mais altamente correlacionada com a resposta do que a publicidade. A direção do PLS não ajusta os preditores tão de perto quanto o PCA, mas faz um trabalho melhor explicando a resposta.

Para identificar a segunda direção do PLS, primeiro ajustamos cada uma das variáveis para \(Z_1\), regredindo cada variável em \(Z_1\) e tomando os resíduos. Esses resíduos podem ser interpretados como as informações restantes que não foram explicadas pela primeira direção do PLS. Em seguida, calculamos \(Z_2\) usando esses dados ortogonalizados exatamente da mesma maneira que \(Z_1\) foi computado com base nos dados originais. Essa abordagem iterativa pode ser repetida \(M\) vezes para identificar múltiplos componentes do PLS \(Z_1, ..., Z_M\). Finalmente, ao final desse procedimento, usamos mínimos quadrados para ajustar um modelo linear para prever \(Y\) usando \(Z_1, ..., Z_M\) exatamente da mesma forma que para o PCR.

Assim como no PCR, o número \(M\) de direções de mínimos quadrados parciais usadas no PLS é um parâmetro de ajuste que é tipicamente escolhido por validação cruzada. Geralmente padronizamos os preditores e a resposta antes de realizar o PLS.

O PLS é popular no campo da quimiometria, onde muitas variáveis surgem de sinais de espectrometria digitalizados. Na prática, muitas vezes ele não apresenta um desempenho melhor do que a regressão ridge ou o PCR. Enquanto a redução supervisionada de dimensão do PLS pode reduzir o viés, ela também tem o potencial de aumentar a variância, de modo que o benefício geral do PLS em relação ao PCR pode ser nulo.

6.4 - Considerações em Altas Dimensões

6.4.1 - Dados de Alta Dimensão

A maioria das técnicas estatísticas tradicionais para regressão e classificação são voltadas para o cenário de baixa dimensão, em que \(n\), o número de observações, é muito maior que \(p\), o número de características. Isso se deve em parte ao fato de que, ao longo da maior parte da história da estatística, a maioria dos problemas científicos que exigiam o uso de estatísticas eram de baixa dimensão. Por exemplo, considere a tarefa de desenvolver um modelo para prever a pressão arterial de um paciente com base em sua idade, sexo e índice de massa corporal (IMC). Existem três preditores, ou quatro se um intercepto for incluído no modelo, e talvez vários milhares de pacientes para os quais a pressão arterial, idade, sexo e IMC estão disponíveis. Portanto, \(n \gg p\), e assim o problema é de baixa dimensão. (Por dimensão aqui estamos nos referindo ao tamanho de \(p\).)

Nos últimos 20 anos, novas tecnologias mudaram a maneira como os dados são coletados em campos tão diversos quanto finanças, marketing e medicina. Agora é comum coletar um número quase ilimitado de medições de características (\(p\) muito grande). Enquanto \(p\) pode ser extremamente grande, o número de observações \(n\) é frequentemente limitado devido ao custo, disponibilidade de amostras ou outras considerações. Dois exemplos são os seguintes:

  1. Em vez de prever a pressão arterial com base apenas na idade, sexo e IMC, pode-se também coletar medições de meio milhão de polimorfismos de nucleotídeo único (SNPs; são mutações individuais de DNA relativamente comuns na população) para inclusão no modelo preditivo. Então \(n \approx 200\) e \(p \approx 500,000\).

  2. Um analista de marketing interessado em entender os padrões de compras online das pessoas poderia tratar como características todos os termos de pesquisa digitados pelos usuários de um motor de busca. Isso às vezes é conhecido como o modelo “bag-of-words”. O mesmo pesquisador pode ter acesso aos históricos de pesquisa de apenas algumas centenas ou alguns milhares de usuários do motor de busca que consentiram em compartilhar suas informações com o pesquisador. Para um dado usuário, cada um dos \(p\) termos de pesquisa é marcado como presente (0) ou ausente (1), criando um grande vetor de características binárias. Então \(n \approx 1,000\) e \(p\) é muito maior.

Conjuntos de dados contendo mais características do que observações são frequentemente chamados de alta dimensão. Abordagens clássicas como a regressão linear de mínimos quadrados não são apropriadas nesse contexto. Muitas das questões que surgem na análise de dados de alta dimensão foram discutidas anteriormente neste livro, pois também se aplicam quando \(n > p\): essas incluem o papel do trade-off viés-variância e o perigo de overfitting. Embora essas questões sejam sempre relevantes, elas podem se tornar particularmente importantes quando o número de características é muito grande em relação ao número de observações.

Definimos o cenário de alta dimensão como o caso em que o número de características \(p\) é maior que o número de observações \(n\). Mas as considerações que discutiremos agora certamente também se aplicam se \(p\) for ligeiramente menor que \(n\), e é melhor sempre mantê-las em mente ao realizar aprendizado supervisionado.

6.4.2 - O Que Dá Errado em Altas Dimensões?

Para ilustrar a necessidade de cuidado extra e técnicas especializadas para regressão e classificação quando \(p > n\), começamos examinando o que pode dar errado se aplicarmos uma técnica estatística não destinada ao cenário de alta dimensão. Para esse propósito, examinamos a regressão de mínimos quadrados. Mas os mesmos conceitos se aplicam à regressão logística, análise discriminante linear e outras abordagens estatísticas clássicas.

Quando o número de características \(p\) é tão grande quanto, ou maior que, o número de observações \(n\), a regressão de mínimos quadrados, conforme descrito no Capítulo 3, não pode (ou melhor, não deve) ser realizada. A razão é simples: independentemente de haver ou não uma relação verdadeira entre as características e a resposta, os mínimos quadrados produzirão um conjunto de estimativas de coeficientes que resultará em um ajuste perfeito aos dados, de forma que os resíduos serão zero.

Um exemplo é mostrado na Figura 6.22 com \(p = 1\) característica (mais um intercepto) em dois casos: quando há 20 observações e quando há apenas duas observações. Quando há 20 observações, \(n > p\) e a linha de regressão de mínimos quadrados não ajusta perfeitamente os dados; em vez disso, a linha de regressão busca aproximar as 20 observações da melhor maneira possível. Por outro lado, quando há apenas duas observações, independentemente dos valores dessas observações, a linha de regressão ajustará exatamente os dados. Isso é problemático porque esse ajuste perfeito quase certamente levará ao sobreajuste dos dados. Em outras palavras, embora seja possível ajustar perfeitamente os dados de treinamento no cenário de alta dimensão, o modelo linear resultante terá um desempenho extremamente ruim em um conjunto de teste independente e, portanto, não constitui um modelo útil. Na verdade, podemos ver que isso aconteceu na Figura 6.22: a linha de mínimos quadrados obtida no painel da direita terá um desempenho muito ruim em um conjunto de teste composto pelas observações no painel da esquerda. O problema é simples: quando \(p > n\) ou \(p \approx n\), uma simples linha de regressão de mínimos quadrados é muito flexível e, portanto, sobreajusta os dados.

A Figura 6.23 ilustra ainda mais o risco de aplicar descuidadamente os mínimos quadrados quando o número de características \(p\) é grande. Os dados foram simulados com \(n = 20\) observações e a regressão foi realizada com entre 1 e 20 características, cada uma das quais completamente não relacionada à resposta. Como mostrado na figura, o \(R^2\) do modelo aumenta para 1 à medida que o número de características incluídas no modelo aumenta, e, correspondentemente, o MSE do conjunto de treinamento diminui para 0 à medida que o número de características aumenta, mesmo que as características sejam completamente não relacionadas à resposta. Por outro lado, o MSE em um conjunto de teste independente torna-se extremamente grande à medida que o número de características incluídas no modelo aumenta, porque a inclusão de preditores adicionais leva a um vasto aumento na variância das estimativas dos coeficientes. Observando o MSE do conjunto de teste, fica claro que o melhor modelo contém, no máximo, algumas variáveis. No entanto, alguém que examina descuidadamente apenas o \(R^2\) ou o MSE do conjunto de treinamento pode erroneamente concluir que o modelo com o maior número de variáveis é o melhor. Isso indica a importância de aplicar um cuidado extra ao analisar conjuntos de dados com um grande número de variáveis e de sempre avaliar o desempenho do modelo em um conjunto de teste independente.

Na Seção 6.1.3, vimos várias abordagens para ajustar o RSS do conjunto de treinamento ou \(R^2\) para levar em conta o número de variáveis usadas para ajustar um modelo de mínimos quadrados. Infelizmente, as abordagens Cp, AIC e BIC não são apropriadas no cenário de alta dimensão, porque estimar \(\sigma^2\) é problemático. (Por exemplo, a fórmula para \(\sigma^2\) do Capítulo 3 resulta em uma estimativa \(\sigma^2 = 0\) nesse cenário.) Da mesma forma, surgem problemas na aplicação do \(R^2\) ajustado no cenário de alta dimensão, já que se pode facilmente obter um modelo com um valor de \(R^2\) ajustado igual a 1. Claramente, são necessárias abordagens alternativas mais adequadas ao cenário de alta dimensão.

6.4.3 - Regressão em Altas Dimensões

Acontece que muitos dos métodos vistos neste capítulo para ajustar modelos de mínimos quadrados menos flexíveis, como seleção progressiva, regressão ridge, o lasso e a regressão por componentes principais, são particularmente úteis para realizar regressão no cenário de alta dimensão. Essencialmente, essas abordagens evitam o sobreajuste usando uma abordagem de ajuste menos flexível do que os mínimos quadrados.

A Figura 6.24 ilustra o desempenho do lasso em um exemplo simulado simples. Existem \(p = 20\), \(50\) ou \(2,000\) características, das quais 20 estão realmente associadas ao resultado. O lasso foi realizado em \(n = 100\) observações de treinamento, e o erro quadrático médio foi avaliado em um conjunto de teste independente. À medida que o número de características aumenta, o erro no conjunto de teste aumenta. Quando \(p = 20\), o menor erro no conjunto de validação foi alcançado quando \(\lambda\) em (6.7) era pequeno; no entanto, quando \(p\) era maior, o menor erro no conjunto de validação foi alcançado usando um valor maior de \(\lambda\). Em cada boxplot, em vez de relatar os valores de \(\lambda\) usados, os graus de liberdade da solução lasso resultante são exibidos; isso é simplesmente o número de estimativas de coeficientes diferentes de zero na solução lasso, e é uma medida da flexibilidade do ajuste lasso. A Figura 6.24 destaca três pontos importantes: (1) regularização ou shrinkage desempenham um papel crucial em problemas de alta dimensão, (2) a seleção apropriada do parâmetro de ajuste é crucial para um bom desempenho preditivo, e (3) o erro no conjunto de teste tende a aumentar à medida que a dimensionalidade do problema (ou seja, o número de características ou preditores) aumenta, a menos que as características adicionais estejam realmente associadas à resposta.

O terceiro ponto acima é, na verdade, um princípio fundamental na análise de dados de alta dimensão, que é conhecido como a maldição da dimensionalidade. Pode-se pensar que à medida que o número de características usadas para ajustar um modelo aumenta, a qualidade do modelo ajustado também aumentará. No entanto, comparando os painéis da esquerda e da direita na Figura 6.24, vemos que isso nem sempre é o caso: neste exemplo, o MSE do conjunto de teste quase dobra à medida que \(p\) aumenta de 20 para 2,000. Em geral, adicionar características de sinal adicionais que estão realmente associadas à resposta melhorará o modelo ajustado, no sentido de levar a uma redução no erro do conjunto de teste. No entanto, adicionar características de ruído que não estão realmente associadas à resposta levará a uma deterioração no modelo ajustado e, consequentemente, a um aumento no erro do conjunto de teste. Isso ocorre porque características de ruído aumentam a dimensionalidade do problema, exacerbando o risco de sobreajuste (já que características de ruído podem ser atribuídas a coeficientes diferentes de zero devido a associações aleatórias com a resposta no conjunto de treinamento) sem qualquer potencial de melhora no erro do conjunto de teste. Assim, vemos que novas tecnologias que permitem a coleta de medições para milhares ou milhões de características são uma faca de dois gumes: podem levar a modelos preditivos melhorados se essas características forem de fato relevantes para o problema em questão, mas levarão a piores resultados se as características não forem relevantes. Mesmo que sejam relevantes, a variância incorrida ao ajustar seus coeficientes pode superar a redução no viés que elas trazem.

6.4.4 - Interpretando Resultados em Altas Dimensões

Quando realizamos o lasso, regressão ridge ou outros procedimentos de regressão no cenário de alta dimensão, devemos ser bastante cautelosos na forma como relatamos os resultados obtidos. No Capítulo 3, aprendemos sobre multicolinearidade, o conceito de que as variáveis em uma regressão podem estar correlacionadas entre si. No cenário de alta dimensão, o problema da multicolinearidade é extremo: qualquer variável no modelo pode ser escrita como uma combinação linear de todas as outras variáveis no modelo. Essencialmente, isso significa que nunca podemos saber exatamente quais variáveis (se houver) realmente são preditivas do resultado, e nunca podemos identificar os melhores coeficientes para usar na regressão. No máximo, podemos esperar atribuir grandes coeficientes de regressão às variáveis que estão correlacionadas com as variáveis que realmente são preditivas do resultado.

Por exemplo, suponha que estamos tentando prever a pressão arterial com base em meio milhão de SNPs, e que a seleção progressiva indica que 17 desses SNPs levam a um bom modelo preditivo nos dados de treinamento. Seria incorreto concluir que esses 17 SNPs preveem a pressão arterial de forma mais eficaz do que os outros SNPs não incluídos no modelo. É provável que haja muitos conjuntos de 17 SNPs que preveriam a pressão arterial tão bem quanto o modelo selecionado. Se obtivermos um conjunto de dados independente e realizarmos a seleção progressiva nesse conjunto de dados, provavelmente obteremos um modelo contendo um conjunto diferente, e talvez até não sobreposto, de SNPs. Isso não diminui o valor do modelo obtido — por exemplo, o modelo pode ser muito eficaz na previsão da pressão arterial em um conjunto independente de pacientes, e pode ser clinicamente útil para os médicos. Mas devemos ter cuidado para não exagerar nos resultados obtidos e deixar claro que o que identificamos é simplesmente um dos muitos modelos possíveis para prever a pressão arterial, e que deve ser validado em conjuntos de dados independentes.

Também é importante ter um cuidado especial ao relatar erros e medidas de ajuste do modelo no cenário de alta dimensão. Vimos que quando \(p > n\), é fácil obter um modelo inútil que tenha resíduos zero. Portanto, nunca se deve usar soma dos erros quadráticos, valores-p, estatísticas \(R^2\) ou outras medidas tradicionais de ajuste do modelo nos dados de treinamento como evidência de um bom ajuste do modelo no cenário de alta dimensão. Por exemplo, como vimos na Figura 6.23, é fácil obter um modelo com \(R^2 = 1\) quando \(p > n\). Relatar esse fato pode levar outros a pensar que um modelo estatisticamente válido e útil foi obtido, quando na verdade isso não fornece absolutamente nenhuma evidência de um modelo convincente. É importante, em vez disso, relatar os resultados em um conjunto de teste independente, ou erros de validação cruzada. Por exemplo, o MSE ou \(R^2\) em um conjunto de teste independente é uma medida válida de ajuste do modelo, mas o MSE no conjunto de treinamento certamente não é.

Escolhendo Entre Modelos Usando a Abordagem do Conjunto de Validação e a Validação Cruzada

Acabamos de ver que é possível escolher entre um conjunto de modelos de diferentes tamanhos usando Cp, BIC e \(R^2\) ajustado. Agora consideraremos como fazer isso usando as abordagens de conjunto de validação e validação cruzada.

Para que essas abordagens gerem estimativas precisas do erro de teste, devemos usar apenas as observações de treinamento para realizar todos os aspectos do ajuste do modelo, incluindo a seleção de variáveis. Portanto, a determinação de qual modelo de um dado tamanho é o melhor deve ser feita usando apenas as observações de treinamento. Este ponto é sutil, mas importante. Se o conjunto de dados completo for usado para realizar a seleção do melhor subconjunto, os erros do conjunto de validação e os erros da validação cruzada que obtivermos não serão estimativas precisas do erro de teste.

Para usar a abordagem do conjunto de validação, começamos dividindo as observações em um conjunto de treinamento e um conjunto de teste. Fazemos isso criando um vetor aleatório, train, com elementos iguais a TRUE se a observação correspondente estiver no conjunto de treinamento, e FALSE caso contrário. O vetor test terá TRUE se a observação estiver no conjunto de teste, e FALSE caso contrário. Note que o ! no comando para criar test faz com que os TRUEs sejam trocados por FALSEs e vice-versa. Também definimos uma semente aleatória para que o usuário obtenha a mesma divisão entre conjunto de treinamento/conjunto de teste.

set.seed(1)

train <- sample(c(TRUE, FALSE), nrow(Hitters),
                replace = TRUE)

test <- (!train)

Agora, aplicamos regsubsets() ao conjunto de treinamento para realizar a seleção do melhor subconjunto.

regfit.best <- regsubsets(Salary ~ ., 
                           data = Hitters[train, ], nvmax = 19)

Note que subdefinimos o data frame Hitters diretamente na chamada para acessar apenas o subconjunto de treinamento dos dados, usando a expressão Hitters[train, ]. Agora, computamos o erro do conjunto de validação para o melhor modelo de cada tamanho de modelo. Primeiro, criamos uma matriz de modelo a partir dos dados de teste.

test.mat <- model.matrix(Salary ~ ., data = Hitters[test, ])

A função model.matrix() é usada em muitos pacotes de regressão para construir uma matriz “X” a partir dos dados. Agora, executamos um loop, e para cada tamanho \(i\), extraímos os coeficientes de regfit.best para o melhor modelo desse tamanho, multiplicamos nas colunas apropriadas da matriz de modelo de teste para formar as previsões e calculamos o MSE do teste.

val.errors <- rep(NA, 19)

for (i in 1:19) {
  coefi <- coef(regfit.best, id = i)
  pred <- test.mat[, names(coefi)] %*% coefi
  val.errors[i] <- mean((Hitters$Salary[test] - pred)^2)
}

 form <- as.formula(object$call[[2]])
 mat <- model.matrix(form, newdata)
 coefi <- coef(object, id = id)
 xvars <- names(coefi)
 mat[, xvars] %*% coefi
}

Agora escrevemos um loop for que realiza a validação cruzada. No \(j\)-ésimo fold, os elementos de folds que são iguais a \(j\) estão no conjunto de teste, e os restantes estão no conjunto de treinamento. Fazemos nossas previsões para cada tamanho de modelo (usando nosso novo método predict()), calculamos os erros de teste no subconjunto apropriado e os armazenamos no slot apropriado na matriz cv.errors. for (j in 1:k) {
  best.fit <- regsubsets(Salary ~ .,
    data = Hitters[folds != j, ],
    nvmax = 19)
  for (i in 1:19) {
    pred <- predict(best.fit, Hitters[folds == j, ], id = i)
  cv.errors[j, i] <- 
    mean((Hitters$Salary[folds == j] - pred)^2)
}
}

6.5.2 - Regressão Crista e o Lasso

Usaremos o pacote glmnet para realizar a regressão de crista (ridge regression) e o lasso. A função principal deste pacote é a glmnet(), que pode ser usada para ajustar modelos de regressão de crista, modelos lasso e mais. Esta função tem uma sintaxe ligeiramente diferente de outras funções de ajuste de modelo que encontramos até agora neste livro. Em particular, devemos passar uma matriz x bem como um vetor y, e não usamos a sintaxe \(y \sim x\). Agora, realizaremos a regressão de crista e o lasso para prever o Salário nos dados do Hitters. Antes de prosseguir, certifique-se de que os valores ausentes foram removidos dos dados, conforme descrito na Seção 6.5.1.

x <- model.matrix(Salary ~ ., Hitters)[, -1]

y <- Hitters$Salary

A função model.matrix() é particularmente útil para criar x; ela não só produz uma matriz correspondente aos 19 preditores, mas também transforma automaticamente quaisquer variáveis qualitativas em variáveis dummy. Esta última propriedade é importante porque glmnet() só pode aceitar entradas numéricas e quantitativas.

Regressão de Crista

A função glmnet() possui um argumento alpha que determina o tipo de modelo ajustado. Se alpha=0, então um modelo de regressão de crista é ajustado, e se alpha=1, então um modelo lasso é ajustado. Primeiro ajustamos um modelo de regressão de crista.
